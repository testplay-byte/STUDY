From the inverse function, we see that:

$\text{Dom } f^{-1}(x) = R - \{1\}$

Hence,

$\text{Dom } f = R - \{2\} = \text{Rang } f^{-1} \quad \text{and} \quad \text{Dom } f^{-1} = R - \{1\} = \text{Rang } f$

(ii)$fof^{-1}(x) = f(f^{-1}(x)) = f\left(\frac{2x}{x-1}\right) = \frac{\frac{2x}{x-1}}{\frac{2x}{x-1}-2} = \frac{2x}{2x-2x+2} = \frac{2x}{2} = x$ (i)

$f^{-1}of(x) = f^{-1}(f(x)) = f^{-1}\left(\frac{x}{x-2}\right) = \frac{2\left(\frac{x}{x-2}\right)}{\frac{x}{x-2}-1} = \frac{2x}{x-x+2} = \frac{2x}{2} = x$ (ii)

From (i) and (ii), we get:

$fof^{-1}(x) = f^{-1}of(x) = x$
