8.7. UNIVERSAL SET OR SPACE SET

A set which contains all elements of all sets under consideration is called universal set or space set and is denoted by U or S.

If $A = \{1, 2, 3\}$, $B = \{3, 4, 5, 6\}$, $C = \{10, 8\}$, $D = \{9, 6\}$

then $U = S = \{1, 2, 3, 4, 5, 6, 8, 9, 10\}$.

8.8. IDENTICAL SETS OR EQUAL SETS

Two sets A and B are said to be identical or equal if they contain exactly the same elements.

If $A = \{1, 2, 3, 4\}$, $B = \{4, 1, 2, 3\}$, A and B are called equal sets.

8.10. OPERATIONS ON SETS

Given a universal set S and its subsets, A, B, C, ..., we can perform on these subsets certain operations that produce other, or perhaps the same, subsets. Among all the operations on sets, we are interested only in union, intersection, difference and complementation.

8.11. UNION OF SETS

Union of the two sets A and B is denoted by $A \cup B$. If A and B are two sets, then $A \cup B$ is a set which contains those elements which belong to A or B, or both, that is

$A \cup B = \{x / x \in A \text{ or } x \in B\}$.

Let $A = \{1, 2, 3\}$ and $B = \{3, 4, 5\}$ then the union of A and B is $A \cup B = \{1, 2, 3, 4, 5\}$

Let $A = \{2, 4, 6\}$ and $B = \{8, 9, 10\}$ then the union of A and B is $A \cup B = \{2, 4, 6, 8, 9, 10\}$
