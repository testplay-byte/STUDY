Example 9.24.

The probability is 0.6 that Mr. A will pass the examination and the probability is 0.8 that Mr. B will pass the examination. Both sit in the examination. Find the probability that somebody will pass the examination.

Solution: Both A and B can pass the examination. Therefore, the events A and B are not mutually exclusive.

Hence, $P(A \cup B) = P(A) + P(B) - P(A \cap B) = 0.6 + 0.8 - (0.6)(0.8) = 0.6 + 0.8 - 0.48 = 0.92$

Note: We have assumed that A and B are independent events that is $P(A \cap B) = P(A)P(B)$

Example 9.25.

A digit is selected at random from the first 20 digits. Let A be the event that the digit is multiple of 4 and B be the event that the digit is multiple of 6. Find the probability (i) $A \cap B$ (ii) $A \cup B$.

Solution: Here, $S = \{1, 2, 3, ..., 20\}$, $n(S) = 20$

$$A = \{4, 8, 12, 16, 20\}, \quad n(A) = 5, \quad P(A) = \frac{n(A)}{n(S)} = \frac{5}{20}$$

$$B = \{6, 12, 18\}, \quad n(B) = 3, \quad P(B) = \frac{n(B)}{n(S)} = \frac{3}{20}$$

$$A \cap B = \{12\}, \quad n(A \cap B) = 1$$

(i) $P(A \cap B) = \dfrac{n(A \cap B)}{n(S)} = \dfrac{1}{20}$

Since A and B are not mutually exclusive events, therefore

(ii) $P(A \cup B) = P(A) + P(B) - P(A \cap B) = \dfrac{5}{20} + \dfrac{3}{20} - \dfrac{1}{20} = \dfrac{7}{20}$

Alternative Method

Here, $S = \{1, 2, 3, ..., 20\}$, $n(S) = 20$, $A = \{4, 8, 12, 16, 20\}$, $B = \{6, 12, 18\}$,

$$A \cup B = \{4, 6, 8, 12, 16, 18, 20\}, \quad n(A \cup B) = 7.$$

Therefore according to classical definition of probability

$$P(A \cup B) = \frac{n(A \cup B)}{n(S)} = \frac{7}{20}$$
