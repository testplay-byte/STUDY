Example 9.35.

Three babies are born in a family. Find the following probabilities:

(i)a family has 3 male babies given that all the 3 babies have the same gender.

(ii)a family has 2 male babies when it is known that the first baby is male.

(iii)a family has 2 girls given that the middle baby is a male.

(iv)a family has 2 male babies given that the first and last babies have the same gender.

Solution: It is assumed that probability of male birth is equal to that of female birth. There are $2^3=8$ possible outcomes in the sample space S. Each outcome has probability of $1/8$. A boy is denoted by b and a girl is denoted by g. The sample space is

$$S = \{bbb, bbg, bgb, bgg, gbb, gbg, ggb, ggg\}, \quad n(S) = 8$$

(i)Let A denote the event "3 male babies" and B denote the event "3 babies have the same gender", then

$$A = \{bbb\}, \quad n(A)=1, \quad P(A) = \frac{n(A)}{n(S)} = \frac{1}{8}$$
$$B = \{ bbb, ggg \}, \quad n(B) = 2, \quad P(B) = \frac{n(B)}{n(S)}=\frac{2}{8}$$
$$A \cap B = \{ bbb \}, \quad n(A \cap B)=1, \quad P(A \cap B) = \frac{n(A \cap B)}{n(S)} = \frac{1}{8}$$
$$\text{Therefore } P(A/B) = \frac{P(A \cap B)}{P(B)} = \frac{1/8}{2/8} = \frac{1}{2} = 0.5$$

(ii)Let A denote the event "2 male babies" and B denote the event "first baby is male" then

$$A = \{ bbg, bgb, gbb \}, \quad n(A)=3, \quad P(A) = \frac{n(A)}{n(S)} = \frac{3}{8}$$
$$B = \{ bbb, bbg, bgb, bgg \}, \quad n(B)=4, \quad P(B) = \frac{n(B)}{n(S)}=\frac{4}{8}$$
$$A \cap B = \{ bbg, bgb \}, \quad n(A \cap B)=2, \quad P(A \cap B) = \frac{n(A \cap B)}{n(S)}=\frac{2}{8}$$
$$\text{Therefore } P(A/B) = \frac{P(A \cap B)}{P(B)} = \frac{2/8}{4/8}=\frac{2}{4}= 0.5$$
