40. If an event $\bar{A}$ is the complement of the event A, then:

  • (a) $A \cup \bar{A} = S$
  • (b) $A \cap \bar{A} = S$
  • (c) $A \cup \bar{A} = \phi$
  • (d) $P(A) = P(\bar{A})$

41. If A is an empty set and B is a non-empty set then:

  • (a) $A \cap B = S$
  • (b) $A \cap B = B$
  • (c) $A \cup B = B$
  • (d) $P(A) = P(B)$

42. Which of the following statements is correct:

  • (a) $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$
  • (b) $A \cup (B \cap C) = (A \cap B) \cap (A \cup C)$
  • (c) $A \cap (B \cap C) = (A \cup B) \cup (B \cap C)$
  • (d) $A \cap (B \cup C) = A + (B \cap C)$

43. Which of the following statement is correct?

  • (a) $A \cap A = \phi$
  • (b) $A \cap A = A'$
  • (c) $A \cup A = A$
  • (d) $A \cap A = S$

44. When the possible outcomes of an experiment are equally likely to occur, then we apply:

  • (a) relative probability
  • (b) subjective probability
  • (c) conditional probability
  • (d) classical probability

45. A number between 0 and 1 that is used to measure uncertainty is called:

  • (a) random variable
  • (b) trial
  • (c) simple event
  • (d) probability

46. Probability lies between:

  • (a) $-1$ and $+1$
  • (b) 0 and 1
  • (c) 0 and n
  • (d) 0 and $\infty$

47. Probability can be expressed as:

  • (a) ratio
  • (b) fraction
  • (c) percentage
  • (d) all of the above

48. The probability of an event cannot be:

  • (a) equal to zero
  • (b) greater than zero
  • (c) equal to one
  • (d) less than zero

49. A measure of the chance that an uncertain event will occur:

  • (a) an experiment
  • (b) an event
  • (c) a probability
  • (d) a trial

50. The probability of all possible outcomes of a random experiment is always equal to:

  • (a) one
  • (b) zero
  • (c) infinity
  • (d) all of the above

51. If an event is impossible, its probability must be:

  • (a) 0
  • (b) 1
  • (c) 0.5
  • (d) $-1$

52. For every event A, probability of A is:

  • (a) $\leq 0$
  • (b) $\geq 0$
  • (c) $> 0$
  • (d) $< 0$

53. When certainty is involved in a situation, its probability is equal to:

  • (a) zero
  • (b) between $-1$ and $+1$
  • (c) between 0 and 1
  • (d) one

54. Which of the following cannot be taken as probability of an event?

  • (a) 0
  • (b) 0.5
  • (c) 1
  • (d) $-1$

55. A letter is chosen at random from the word "Statistics". The probability of getting a vowel is:

  • (a) 1/10
  • (b) 2/10
  • (c) 3/10
  • (d) 4/10

56. A single letter is selected from the word "PROBABILITY". Then the probability of vowels is:

  • (a) 2/11
  • (b) 3/11
  • (c) 4/11
  • (d) 7/11

57. A single letter is selected from the world "PUBLICATION", then the probability of consonants is equal to:

  • (a) 5/11
  • (b) 6/11
  • (c) 0
  • (d) 1

58. The probability based on the concept of relative frequency is called:

  • (a) empirical probability
  • (b) statistical probability
  • (c) both (a) and (b)
  • (d) neither (a) nor (b)

59. The events having no experimental outcomes in common is called:

  • (a) equally likely events
  • (b) exhaustive events
  • (c) mutually exclusive events
  • (d) Independent events

  • (a) 1
  • (b) 0
  • (c) $1 - A$
