Basic Statistics Part-II · Chapter 9 — Probability — page 40 (printed 50)

61.When each outcome of a sample space is as likely to occur as any other, the outcomes are called:

(a) exhaustive(b) mutually exclusive(c) equally likely(d) not mutually exclusive

62.If n( A ) = n( B ), then A and B are ________ events.

(a) mutually exclusive(b) equally likely(c) exhaustive(d) compound

63.When the occurrence of one event has no effect on the probability of the occurrence of another event, the events are called:

(a) independent(b) dependent(c) mutually exclusive(d) equally likely

64.The six faces of the die are called equally likely if the die is:

(a) small(b) fair(c) six-faced(d) round.

65.Two events A and B are called mutually exclusive if:

(a) $A \cup B = \phi$(b) $A \cap B = \phi$(c) $A \cap B = S$(d) $A \cap B = 1$

66.If A and B are two mutually exclusive events, then:

(a) $P(A \cap B) = 0$(b) $P(A \cap B) = 1$(c) $P(A \cup B) = 0$(d) $P(A \cap B) = S$.

67.When A and B are two non-empty and mutually exclusive events, then:

(a) $P(A \cup B) = P(A) . P(B)$(b) $P(A \cup B) = P(A) + P(B)$(c) $P(A \cap B) = P(A) . P(B)$(d) $P(A \cap B) = P(A) + P(B)$

68.The two events A and B are called not mutually exclusive events if:

(a) $A \cap B = \phi$(b) $A \cap B \neq \phi$(c) $A \cup B = \phi$(d) $A \cap B = \text{zero}$

69.If A and B are disjoint events then the statement which is always true is:

(a) $P(A/B) = 0$(b) $P(A \cup B) = 0$(c) $P(A \cap B) = 1$(d) $P(A) = P(B)$

70.The events A, B and C are called exhaustive events if:

(a) $A \cup B \cup C = S$(b) $A \cap B \cap C = S$(c) $A \cup B \cup C = \phi$(d) $A \cup B \cup C = \text{zero.}$

71.If A and B are two non-mutually exclusive events, then $P(A \cup B)$ is:

(a) $P(A) + P(B)$(b) $P(A) + P(B) - P(A \cap B)$(c) $P(A) P(B)$(d) $P(B) P(A/B)$

72.If A and B are not-mutually exclusive events, then:

(a) $P(A \cup B) + P(A \cap B) = P(A) + P(B)$(b) $P(A \cup B) = P(A) + P(B)$(c) $P(A \cup B) = P(A) P(B)$(d) $P(A \cap B) = P(A) + P(B)$

73.If A and B are independent events, then:

(a) $P(A \cup B) = P(A) P(B)$(b) $P(A \cap B) = P(A) P(B)$(c) $P(A \cap B) = P(A) + P(B)$(d) $P(A) = P(B)$

74.If A and B are two independent events, then:

(a) $P(A/B) = P(A)$(b) $P(A) = P(B)$(c) $P(A) < P(B)$(d) $P(A/B) = P(B/A)$.

75.A and B are two independent events. Which one of these equations is false?

(a) $P(A \cap \bar{B}) = P(A) P(\bar{B})$(b) $P(\bar{A} \cap \bar{B}) = P(\bar{B} \cap \bar{A})$(c) $P(\bar{A} \cap \bar{B}) = P(\bar{A}) P(\bar{B})$(d) $P(A \cup B) = P(A) P(B)$

76.If A is an empty set (φ) and S is the sample space then:

(a) $P(A \cup S) = P(S)$(b) $P(A \cup S) = P(\phi)$(c) $P(A \cap S) = 1$(d) $P(A \cup S) = \text{zero}$

77.The joint probability of two independent events A and B is:

(a) $P(A) + P(B)$(b) $P(A) + P(B) - P(A \cap B)$(c) $P(A) P(A/B)$(d) $P(A) P(B)$

78.If A and B are any two events, then $P(A \cup \bar{B})$ is equal to:

(a) $1 + P(A \cap B)$(b) $1 - P(A \cup B)$(c) $1 - P(A \cap B)$(d) $P(A) + P(B)$

79.If A and B are any two events, then $P(\bar{A} \cap \bar{B})$ is equal to:

(a) $1 - P(A \cup B)$(b) $1 - P(A \cap B)$(c) $1 - P(\bar{A} \cap B)$(d) $1 - P(A \cap \bar{B})$

80.If we toss a coin and $P(H) = 2P(T)$, then probability of head is equal to:

(a) $0$(b) $1/2$(c) $1/3$(d) $2/3$
