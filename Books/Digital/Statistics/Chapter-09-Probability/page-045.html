Q.71Given P( A ) = 2/3, P( A ∪ B ) = 7/12 and P( A ∩ B ) = 5/12. Suppose A and B are any two events, determine P( B ).

Ans. 1/3

Q.72A fair die is rolled. Find the probability of getting even face or face more than 4.

Ans. 2/3

Q.73A coin is tossed four times and the outcome is recorded for each toss. List the sample points for the experiment.

Ans. There are 16 equally likely outcomes:

HHHH　　HHHT　　HHTH　　HHTT

HTHH　　HTHT　　HTTH　　HTTT

THHH　　THHT　　THTH　　THTT

TTHH　　TTHT　　TTTH　　TTTT

Q.74Given P( A ) = 0.3, P( B ) = 0.4 and P( A and B ) = 0.20. Are A and B statistically independent?

Ans. No, because $P(\text{A and B}) \neq P(A)P(B)$

Q.75Given P( A ) = 0.7 and P( B ) = 0.6. If A and B are statistically independent then find P( A and B ).

Ans. 0.42

Q.76Given P(A) = 0.4, P( A ∪ B ) = 0.7 and P( B ) = p. Suppose A and B are independent events, find the value of p.

Ans. 0.5

Q.77Consider drawing two cards from a pack of 52 playing cards:

Let Event A = the first card is a heart and

Event B = the second card is a red card

Calculate P( A and B ).

Ans. P( A ) = 1/4, P( B/A ) = 25/51, P( A and B ) = 0.123

Q.78If P( A ) = 0.2, P( B ) = 0.4 and P( A/B ) = 0.375, find P( A and B ).

Ans. 0.15

Q.79Given P( A/B ) = 1/5 and P( B/A ) = 1/2. Find P( A ) / P( B ).

Ans. 2/5

Q.80Given P( A ) = 1/3, P( B ) = 1/4 and P( A/B ) = 1/6. Find P( B/A ).

Ans. 1/8

Q.81If P( A ) = 0.7, P( B ) = 0.5 and P( B/A ) = 0.5, find P( A and B ).

Ans. 0.35

Q.82If P( A and B ) = 0.4 and P( B ) = 0.8, find P( A/B ).

Ans. 0.5

Q.83If A and B are two independent events, such that P( A ) = 0.2 and P( B ) = 0.15. Find $P(A \cap B)$ and P( A/B ).

Ans. 0.03 and 0.2

Q.84Given P( A ) = 5/9, P( B ) = 4/9 and P( B/A ) = 2/5. Find P( A/B ).

Ans. 0.5

Q.85If $P(A \cap B) = \frac{1}{4}$ and $P(A) = \frac{1}{2}$. Find P( B/A ).

Ans. 0.5

Q.86Given P( A ) = 1/3, P( B ) = 3/4 and P( A ∪ B ) = 11/12. Find P( B/A ).

Ans. 1/2

Q.87Two coins are tossed. Determine the probability of getting two heads given that there is at least one head.

Ans. 1/3

Q.88A fair die is rolled. What is the probability of getting even face given that face is less than 5?

Ans. 1/2

Q.89Two dice are rolled. What is the probability of getting a total of 4 given that both faces are similar.

Ans. 1/6

Q.90What is the probability of obtaining two kings in drawing two cards from a shuffled deck of cards? If the first card is not replaced before the second card is drawn.

Ans. 1/221
