**Example 38:** Find the approximated value of $\sqrt{25.4}$.

**Solution:** First, identify the function $f(x) = \sqrt{x}$

We wish to calculate the approximated value of $f(x + \Delta x) = \sqrt{x + \Delta x}$ when $x = 25$ and $\Delta x = 0.4$; $(25.4 = 25 + 0.4)$

Now, $dy = \frac{1}{2}x^{\frac{-1}{2}}dx = \frac{1}{2\sqrt{x}}\Delta x$

We have; $f(x + \Delta x) = f(x) + dy$
$$= f(x) + \frac{1}{2\sqrt{x}}\Delta x = \sqrt{x} + \frac{1}{2\sqrt{x}}\Delta x = \sqrt{25} + \frac{1}{2\sqrt{25}}(0.4) = 5.04$$
