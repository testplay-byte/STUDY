## 2.19 Extrema of Functions

Suppose a function $f$ is defined on an interval I. The maximum and minimum values of $f$ on I (if exist) are said to be extrema of the functions. We have two kinds of extrema.

> **Definition: Absolute Extrema**
> 
> i. A number $f(c)$ is an **Absolute Maximum** of a function $f$ if $f(x) \leq f(c)$ for every $x$ in the domain of $f$.
> 
> ii. A number $f(c)$ is an **Absolute Minimum** of a function $f$ if $f(x) \geq f(c)$ for every $x$ in the domain of $f$.

Absolute extrema are called global extrema. Figure shows several possibilities:

[Figure F1] [Figure F2] [Figure F3] [Figure F4]

**Example 43:**

i. For $f(x) = \sin x$, $f\left(\frac{\pi}{2}\right) = 1$ is its absolute maximum and $f\left(\frac{3\pi}{2}\right) = -1$ is its absolute minimum.

[Figure F5]

ii. The function $f(x) = x^2$ has the absolute minimum $f(0) = 0$ but has no absolute maximum.

[Figure F6]

iii. $f(x) = \frac{1}{x}$ has neither an absolute maximum nor an absolute minimum.
