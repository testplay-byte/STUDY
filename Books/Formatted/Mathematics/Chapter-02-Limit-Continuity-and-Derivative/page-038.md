**Example 48:** Find the critical point and also relative extrema by second derivative test for $f(x) = x^4 - x^2$.

**Solution:** $f'(x) = 4x^3 - 2x = 2x(2x^2 - 1)$

$f''(x) = 12x^2 - 2$

For critical values take $f'(x) = 0$

$$\begin{aligned} 2x(2x^2 - 1) &= 0 \\ x &= 0, \frac{-\sqrt{2}}{2}, \frac{\sqrt{2}}{2} \end{aligned}$$

The second derivative test is summarized as:

| $x$ | Sign of $f''(x)$ | $f(x)$ | Conclusions |
| :--- | :--- | :--- | :--- |
| 0 | $f''(x) = -ve$ | 0 | Rel. max |
| $\frac{\sqrt{2}}{2}$ | $f''(x) = +ve$ | $\frac{-1}{4}$ | Rel. min |
| $\frac{-\sqrt{2}}{2}$ | $f''(x) = +ve$ | $\frac{-1}{4}$ | Rel. min |
