## 4.4.2 Number of Solutions

A given differential equation usually possesses an infinite number of solutions. e.g.,

(i) For any value of $c$, the function $y = \frac{c}{x} + 1$ is a solution of the **first order** differential equation:

$$x\frac{dy}{dx} + y = 1 \quad \text{on the interval } (0, \infty)$$

The solution $y = \frac{c}{x} + 1$ represents infinite number of solutions for various values of $c$. In particular, for $c = 0$, we obtain a constant solution $y = 1$.

(ii) The functions $y = c_1 \cos 4x$ and $y = c_2 \sin 4x$ where $c_1$ and $c_2$ are arbitrary constants, are solutions of the differential equation:

$$y'' + 16y = 0$$

It is to be noted that the sum of solutions $y = c_1 \cos 4x$ and $y = c_2 \sin 4x$:

$$y = c_1 \cos 4x + c_2 \sin 4x$$

is also a solution of differential equation $y'' + 16y = 0$.

(iii) $y = mx + c$ &nbsp;&nbsp; (iv) $y = bx^2 + 2ax$
