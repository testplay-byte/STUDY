For acceleration we differentiate the velocity:

$$\begin{aligned} \boldsymbol{a}(t) &= \frac{d}{dt}\boldsymbol{v}(t) = \frac{d}{dt}(4t)\hat{\boldsymbol{i}} + \frac{d}{dt}(12t^3)\hat{\boldsymbol{j}} - \frac{d}{dt}(3t^2)\hat{\boldsymbol{k}} \\ \boldsymbol{a}(t) &= 4 \times 1\hat{\boldsymbol{i}} + 12 \times 3t^2\hat{\boldsymbol{j}} - 3 \times 2t\hat{\boldsymbol{k}} = 4\hat{\boldsymbol{i}} + 36t^2\hat{\boldsymbol{j}} - 6t\hat{\boldsymbol{k}} \\ \therefore \quad \boldsymbol{a}(1) &= 4\hat{\boldsymbol{i}} + 36(1)^2\hat{\boldsymbol{j}} - 6(1)\hat{\boldsymbol{k}} = 4\hat{\boldsymbol{i}} + 36\hat{\boldsymbol{j}} - 6\hat{\boldsymbol{k}} \end{aligned}$$

## Exercise 5.3

1. If $\boldsymbol{r}(t)$ is the position of the particle. Find its domain and the range at **given point**. Also find its first and second derivative.

   i. $\quad \boldsymbol{r}(t) = (t+1)\boldsymbol{i} + (t^2-1)\boldsymbol{j} + 5t\boldsymbol{k}, \quad t=2$

   ii. $\quad \boldsymbol{r}(t) = \frac{t}{t+1}\boldsymbol{i} + \frac{1}{t}\boldsymbol{j} + t^3\boldsymbol{k}, \quad t=-\frac{1}{2}$

   iii. $\quad \boldsymbol{r}(t) = e^t\boldsymbol{i} + \frac{2}{9}e^{2t}\boldsymbol{j} + 5e^{-t}\boldsymbol{k}, \quad t=\ln 2$

   iv. $\quad \boldsymbol{r}(t) = (\cos 2t)\boldsymbol{i} + (3\sin 2t)\boldsymbol{j} + 5t\boldsymbol{k}, \quad t=0$

2. Find the velocity and acceleration of the function at $t=0$

   i. $\quad \boldsymbol{r}(t) = (3t+1)\boldsymbol{i} + \sqrt{3}t\boldsymbol{j} + t^2\boldsymbol{k}$

   ii. $\quad \boldsymbol{r}(t) = \left(\frac{t}{\sqrt{2}}\right)\boldsymbol{i} + \left(\frac{t}{\sqrt{2}} - 16t^2\right)\boldsymbol{j} - 2t\boldsymbol{k}$

   iii. $\quad \boldsymbol{r}(t) = (\ln(t^2+1))\boldsymbol{i} + (\tan^{-1}t)\boldsymbol{j} + \sqrt{t^2+1}\boldsymbol{k}$

   iv. $\quad \boldsymbol{r}(t) = \frac{4}{9}(t+1)^{3/2}\boldsymbol{i} + \frac{4}{9}(1-t)^{3/2}\boldsymbol{j} + \frac{1}{3}t\boldsymbol{k}$

3. Find the scalar valued function in term of the magnitude

   i. $\quad \boldsymbol{r}(t) = (3t-7)\boldsymbol{i} + t\boldsymbol{j} - t^2\boldsymbol{k}$

   ii. $\quad \boldsymbol{r}(t) = \left(\frac{t}{\sqrt{2}}\right)\boldsymbol{i} + \left(\frac{t}{\sqrt{2}} + 16t^2\right)\boldsymbol{j} - 2t\boldsymbol{k}$

   iii. $\quad \boldsymbol{r}(t) = (\ln(t^2+1))\boldsymbol{i} + (\tan t)\boldsymbol{j} + \sec t\,\boldsymbol{k}$

   iv. $\quad \boldsymbol{r}(t) = \frac{4}{9}(t+1)^{3/2}\boldsymbol{i} + \frac{4}{9}(1-t)^{3/2}\boldsymbol{j} + \frac{1}{3}t^{3/2}\boldsymbol{k}$
