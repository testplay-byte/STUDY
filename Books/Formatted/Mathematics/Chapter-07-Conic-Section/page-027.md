# Page 27 — Unit 07: Conic Section

> 📄 Original scan: [0027.jpg](../../../Raw/Mathematics/Unit-07-Conic-Section/0027.jpg) · printed page 208

If Disc > 0 then equation will have two distinct real roots so, line will cut the ellipse at two different points.

If Disc < 0 then equation will have no real roots, i.e. there is no common point.

If Disc = 0 then equation will have one real root i.e. there is only one common point. Thus line will be tangent to the ellipse if Disc = 0.

$$\begin{aligned} &\Rightarrow \{-2b^2h + 2a^2m(c - k)\}^2 - 4(b^2 + a^2m^2)[b^2h^2 + a^2(c - k)^2 - a^2b^2] = 0 \\ &\Rightarrow 4\{-b^2h + a^2m(c - k)\}^2 - 4(b^2 + a^2m^2)[b^2h^2 + a^2(c - k)^2 - a^2b^2] = 0 \\ &\Rightarrow b^4h^2 + a^4m^2(c - k)^2 - 2a^2b^2hm(c - k) - b^4h^2 - a^2b^2(c - k)^2 + a^2b^4 - a^2b^2m^2h^2 \\ &\qquad\quad - a^4b^2m^2h^2 - a^4m^2(c - k)^2 - a^4b^2m^2 = 0 \end{aligned}$$

Taking common $-a^2b^2$

$$\begin{aligned} &-a^2b^2[2hm(c - k) + (c - k)^2 - b^2 + m^2h^2 + a^2m^2] = 0 \\ &\Rightarrow 2hm(c - k) + (c - k)^2 - b^2 + m^2(a^2 + h^2) = 0 \\ &\Rightarrow b^2 = 2hm(c - k) + (c - k)^2 + m^2(a^2 + h^2) \end{aligned}$$

is the condition for the line to be tangent to the ellipse. In particular when centre of the ellipse is at u (0,0) then $h = 0$ and $k = 0$. In this case the condition reduces to

$$\begin{aligned} &b^2 = 2(0)m(c - 0) + (c - 0)^2 + m^2(a^2 + 0) \\ &\Rightarrow b^2 = c^2 + m^2a^2 \\ &\Rightarrow c^2 = b^2 - m^2a^2 \\ &\Rightarrow c = \sqrt{b^2 - m^2a^2} \qquad \text{provided that } b^2 - m^2a^2 \geq 0 \end{aligned}$$

Put value in equation (2)

$$y = mx \pm \sqrt{b^2 - m^2a^2}$$

Are the equations of the tangents to the ellipse $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ in the slope form.

**Example 20:** Find the equations of the tangent to the ellipse $\frac{x^2}{2} + \frac{y^2}{16} = 1$ with slope $\frac{1}{2}$.

**Solution:** Equation of the ellipse is $\frac{x^2}{2} + \frac{y^2}{16} = 1$.

Here $a^2 = 2; \quad b^2 = 16$ and given that $m = \frac{1}{2}$.

Equations of the tangent to ellipse are $y = mx \pm \sqrt{b^2 - m^2a^2}$

Putting the values; we have:

$$y = \frac{1}{2}x \pm \sqrt{16 - \frac{1}{4}(2)} \;\Rightarrow\; y = \frac{1}{2}x \pm \frac{\sqrt{62}}{2} \;\Rightarrow\; 2y = x \pm \sqrt{62}$$

are the required equations of the tangent lines.

**Example 21:** prove that the line $\sqrt{3}x - 2y + 8 = 0$ is tangent to the ellipse $\frac{x^2}{16} + \frac{y^2}{4} = 1$.

**Solution:**

Equation of line is $\qquad \sqrt{3}x - 2y + 8 = 0 \tag{1}$

and equation of ellipse is $\frac{x^2}{16} + \frac{y^2}{4} = 1$

$$x^2 + 4y^2 = 16 \tag{2}$$
