# Page 3 — Unit 08: Inverse Trigonometric Functions and Their Graphs

**Example 1:** Find the principal value of $\text{Cos}^{-1}\left(-\frac{1}{2}\right)$

**Solution:** Let $y = \text{Cos}^{-1}\left(-\frac{1}{2}\right)$ then $\text{Cos } y = -\frac{1}{2}$, where $y \in [0, \pi]$

Consider $\text{Cos } y = -\frac{1}{2}$ $\left[\text{We need to find } y \text{ whose cosine value is } -\frac{1}{2}\right]$

$$\Rightarrow \text{Cos } y = \text{Cos}\left(\frac{2\pi}{3}\right) \quad \text{Since } \text{Cos } y < 0 \Rightarrow y \text{ lies in Quad II.}$$

$$\Rightarrow y = \frac{2\pi}{3} \Rightarrow \text{Cos}^{-1}\left(-\frac{1}{2}\right) = \frac{2\pi}{3}$$

## 8.1.2 The Inverse Cosine Function

For the cosine function $y = \text{Cos } x$ where $x \in [0, \pi]$ and $y \in [-1, 1]$, we define an inverse cosine function $y = \text{Cos}^{-1}(x)$ where $x \in [-1, 1]$ and $y \in [0, \pi]$. For $x \in [-1, 1]$, $y = \text{Cos}^{-1} x$ is a real number in the interval $[0, \pi]$ whose cosine is $x$.

In view of above, we observe that:

$\text{Cos}^{-1}(1) = 0$ since $\text{Cos}(0) = 1$

$\text{Cos}^{-1}(0) = \frac{\pi}{2}$ since $\text{Cos}\left(\frac{\pi}{2}\right) = 0$

$\text{Cos}^{-1}(-1) = \pi$ since $\text{Cos } \pi = -1$

[Figure F1]

> If $y = \text{Cos } x$ with $x \in [0, \pi]; y \in [-1, 1]$ then
> $y = \text{Cos}^{-1}(x)$ with $x \in [-1, 1]; y \in [0, \pi]$

## 8.1.3 The Domain and Range of Inverse Cosine Function

To find the domain and range of inverse trigonometric function, switch the domain and range of the original function.

For the cosine function $y = \text{Cos } x$

$$Domain = [0, \pi] \text{ and } Range = [-1, 1]$$

For the inverse cosine function $y = \text{Cos}^{-1} x$

$$Domain = [-1, 1] \text{ and } Range = [0, \pi]$$

> The inverse trigonometric function's domain is a real number and its range is a real angle measured in degree or radian.

Since graph of the inverse trigonometric function is a reflection of the graph of the original function about the line $y = x$.

Therefore, to graph the inverse trigonometric function, we use the graph of the trigonometric function restricted to the domain specified earlier and reflect the graph about the line $y = x$ as shown below.
