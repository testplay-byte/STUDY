## 8.1.4 The Principal Sine Function

To define principal sine function, we need an interval for $x$ where there is only one solution to $\text{sin}x = k$ for $k \in [-1, 1]$. Such a solution is possible in the interval $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$.

In the interval $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$, we can find a **unique solution** to the equation $\text{Sin } x = k$, where $k \in [-1, 1]$. We write this solution as $x = \text{Sin}^{-1} k$.

In other words, “$x$ is a real number in the interval $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ whose sine value is $k$”.

The sine function defined on $x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ for which there is only **one solution** of the equation $\text{Sin } x = k$ where $k \in [-1, 1]$ is called the **Principal Sine Function**.

[Figure F1]

$$\boxed{\text{Sinx} = \text{sinx}\ ;\ x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]}$$

> * $\text{Sin}^{-1}$ and $\text{sin}$ are not inverses of each other (They do not cancel each other)
> * $\text{sin}$ does not have an inverse
> * The functions that are inverses are $\text{Sin}^{-1}$ and $\text{Sin}$.

**Example 2:** Find the principal value of $\text{Sin}^{-1}\left(-\frac{1}{\sqrt{2}}\right)$

**Solution:** Let $y = \text{Sin}^{-1}\left(-\frac{1}{\sqrt{2}}\right)$ then $\text{Sin } y = -\frac{1}{\sqrt{2}}$, where $y \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$

Consider $\text{Sin } y = -\frac{1}{\sqrt{2}} \quad \left[\text{We need to find } y \text{ whose sine value is } -\frac{1}{\sqrt{2}}.\right]$

$\Rightarrow \text{Sin } y = \text{Sin}\left(-\frac{\pi}{4}\right)$ Since $\text{Siny} < 0 \Rightarrow y$ lies in Quad – IV.

$\Rightarrow y = -\frac{\pi}{4}$

$\Rightarrow \text{Sin}^{-1}\left(-\frac{1}{\sqrt{2}}\right) = -\frac{\pi}{4}$

## 8.1.5 The Inverse Sine Function

For the sine function $y = \text{Sin } x$ where $x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ and $y \in [-1, 1]$ we define an inverse sine function

$y = \text{Sin}^{-1}(x)$ where $x \in [-1, 1]$ and $y \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$.

In view of above, we observe that:

$\text{Sin}^{-1}(-1) = -\frac{\pi}{2}$ since $\text{Sin}\left(-\frac{\pi}{2}\right) = -1$

$\text{Sin}^{-1}\left(\frac{1}{\sqrt{2}}\right) = \frac{\pi}{4}$ since $\text{Sin}\left(\frac{\pi}{4}\right) = \frac{1}{\sqrt{2}}$

$\text{Sin}^{-1}(1) = \frac{\pi}{2}$ since $\text{Sin}\left(\frac{\pi}{2}\right) = 1$
