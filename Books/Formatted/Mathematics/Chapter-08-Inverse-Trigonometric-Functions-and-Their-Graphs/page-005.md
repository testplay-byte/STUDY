## 8.1.6 The Domain and Range of Inverse Sine Function

To find the domain and range of inverse trigonometric function, switch the domain and range of the original function.

For the sine function $y = \text{Sin } x$

$Domain = \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ and $Range = [-1, 1]$

For the inverse sine function $y = \text{Sin}^{-1}x$

$Domain = [-1, 1]$ and $Range = \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$

> If $y = \text{Sin } x$ with $x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]; y \in [-1, 1]$
> Then $y = \text{Sin}^{-1}(x)$ with
> $x \in [-1, 1]; y \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$

Since graph of the inverse trigonometric function is a reflection of the graph of the original function about the line $y = x$.

Therefore, to graph the inverse trigonometric function, we use the graph of the trigonometric function restricted to the domain specified earlier and reflect the graph about the line $y = x$ as shown below.

> **Key Facts**
> *   The expression $\text{Sin}^{-1}x$ is not the same as $\frac{1}{\text{Sinx}}$. In other words, $-1$ is not an exponent. It simply means the inverse function.
> *   Remember that there will be no solution if $k$ lies outside the interval $[-1, 1]$
> *   $\text{Cos}x = \text{cos}x ; x \in [0, \pi]$
> *   $\text{Cos}^{-1}$ and **cos** are not inverses of each other. (They do not cancel each other)
> *   **cos** does not have an inverse The functions that are inverses are: **Cos$^{-1}$** and **Cos**

## 8.1.7 The Principal Tangent Function

We know that an infinite number of $x$ values can be found from $y = \text{tan}x = 1$ for each $x \in R - (2n + 1)\frac{\pi}{2}$ where $n \in Z$. By this, one can record infinitely many solutions to the equation $\text{tan}x = k$ where $k \in (-\infty, +\infty)$. If we need an interval for $x$ where there is only one solution to $\text{tan}x = k$ for $k \in (-\infty, +\infty)$, we choose the interval between $-\frac{\pi}{2}$ and $+\frac{\pi}{2}$.

In the interval $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$, we can find a **unique solution** to the equation $\text{Tan}x = k$, where $k \in (-\infty, \infty)$.
