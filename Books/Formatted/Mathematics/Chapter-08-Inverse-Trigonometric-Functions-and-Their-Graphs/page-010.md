## 8.1.16 The Principal Cosecant Function

The graph of cosecant function from $-2\pi$ to $+2\pi$ is shown in the adjoining figure.

From the graph it is clear that $\csc x = k$ for $k \in R - (-1, 1)$, has many solutions.

To define principal cosecant function, we need an interval for $x$ where there is only one solution to $\csc x = k$ for $k \in R - (-1, 1)$.

Such a solution is possible in the interval from $-\frac{\pi}{2}$ to $+\frac{\pi}{2}$ except 0. In the interval $x \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$, $x \neq 0$, we can find a **unique solution** to the equation $\text{Csc } x = k$, where $k \in R - (-1, 1)$.

We write this solution as $x= \text{Csc}^{-1}k$. In other words, "$x$ is a real number in the interval $\left[-\frac{\pi}{2} 0\right) \cup (0,\frac{\pi}{2}\right]$ whose cosecant value is $k$". The cosecant function defined on $x \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right), x \neq 0$ for which there is only **one solution** of the equation $\text{Csc } x = k$ where $k \in R - (-1, 1)$ is called the **Principal Cosecant Function**.

[Figure F2]

**Example 6:** Find the principal value of $\text{Csc}^{-1}(2)$.

**Solution:** Let $y = \text{Csc}^{-1}(2)$ if and only if
$\csc y = (2)$, where $y \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right], y \notin 0$.
Consider $\csc y = (2)$ [We need to find $y$ whose cosecant value is (2).]
$$\begin{aligned}
&\Rightarrow \text{Sin } y = \frac{1}{2} \quad \text{Since, Siny} > 0 \Rightarrow \text{Csc } y > 0 \Rightarrow y \text{ lies in Quad I.} \\
&\Rightarrow \text{Sin } y = \text{Sin}\left(\frac{\pi}{6}\right) \\
&\Rightarrow y = \frac{\pi}{6} \\
&\Rightarrow \text{Csc}^{-1}(2) = \frac{\pi}{6}
\end{aligned}$$
