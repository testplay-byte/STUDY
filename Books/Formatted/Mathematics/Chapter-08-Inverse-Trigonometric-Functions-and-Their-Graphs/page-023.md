## Exercise 8.2

1. Draw graph of each of the following functions against the intervals mentioned:

   i. $y = \text{Cos}^{-1}(x^2) \text{ for } x \in [-1, 1]$
   
   ii. $y = \text{Sin}^{-1}(2x) \text{ for } x \in [-\frac{1}{2}, \frac{1}{2}]$.
   
   iii. $y = \text{Tan}^{-1}(x^2) \text{ for } x \in \mathbb{R}$

   viii. $y = \text{Sin}^{-1}(-x) \text{ for } x \in [-1, 1]$
   
   ix. $y = \text{Tan}^{-1}(3x + 1) \text{ for } x \in \mathbb{R}$
   
   x. $y = \text{Cos}^{-1}(2x - 1) \text{ for } x \in [0, 1]$
