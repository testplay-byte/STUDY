**Example 12:** Show that: $\text{Tan}^{-1}(2) + \text{Tan}^{-1}(3) = -\frac{\pi}{4}$

**Solution:** L.H.S. $= \text{Tan}^{-1}(2) + \text{Tan}^{-1}(3)$

Applying the inverse tangent addition formula.

$$\begin{aligned}
\text{L.H.S} &= \text{Tan}^{-1}\left(\frac{2+3}{1-(2)(3)}\right) = \text{Tan}^{-1}\left(\frac{5}{1-6}\right) \\
&= \text{Tan}^{-1}\left(-\frac{5}{5}\right) = \text{Tan}^{-1}(-1) \\
&= -\frac{\pi}{4} = \text{R. H. S}
\end{aligned}$$

## 8.3.4 Inverse Cotangent Addition and Subtraction Formulas

(i) $\text{Cot}^{-1}(x) + \text{Cot}^{-1}(y) = \text{Cot}^{-1}\left(\frac{xy-1}{x+y}\right)$, where $x, y \neq 0$ and $xy > 1$

(ii) $\text{Cot}^{-1}(x) - \text{Cot}^{-1}(y) = \text{Cot}^{-1}\left(\frac{xy+1}{y-x}\right)$, where $x \neq y$

**Proof:**

(i) Let $\alpha = \text{Cot}^{-1}(x)$ if and only if $\text{Cot } \alpha = x$, where $\alpha \in (0, \pi)$ and $x \in (-\infty, +\infty)$

Let $\beta = \text{Cot}^{-1}(y)$ if and only if $\text{Cot } \beta = y$, where $\beta \in (0, \pi)$ and $x \in (-\infty, +\infty)$

Using the cotangent addition formula

$$\text{Cot}(\alpha + \beta) = \frac{\text{Cot } \alpha \text{Cot } \beta - 1}{\text{Cot } \alpha + \text{Cot } \beta}$$

[Figure F1]

Applying arc function on both sides:

$$\alpha + \beta = \text{Cot}^{-1}\left(\frac{\text{Cot } \alpha \text{Cot } \beta - 1}{\text{Cot } \alpha + \text{Cot } \beta}\right) \longrightarrow (\text{IV})$$

If $\text{Cot } \alpha > 0$ and $\text{Cot } \beta > 0$ then $\alpha, \beta \in \left(0, \frac{\pi}{2}\right)$.

Substituting values in equation (IV), we have:

$$\text{Cot}^{-1}(x) + \text{Cot}^{-1}(y) = \text{Cot}^{-1}\left(\frac{xy-1}{x+y}\right)$$

> **Check Point**

(ii) The proof is similar to subtraction formula.

**Example 13:** Show that: $\text{Cot}^{-1}\left(\frac{11}{27}\right) - \text{Cot}^{-1}\left(\frac{19}{8}\right) = \frac{\pi}{4}$

**Solution:** L.H.S. $= \text{Cot}^{-1}\left(\frac{11}{27}\right) - \text{Cot}^{-1}\left(\frac{19}{8}\right)$

Applying the inverse cotangent subtraction formula

$$\begin{aligned}
\text{L.H.S} &= \text{Cot}^{-1}\left(\frac{\left(\frac{11}{27}\right)\left(\frac{19}{8}\right)+1}{\frac{19}{8}-\frac{11}{27}}\right) = \text{Cot}^{-1}\left(\frac{\frac{209}{216}+1}{(513-88)/216}\right) \\
&= \text{Cot}^{-1}\left(\frac{(209+216)/216}{(425)/216}\right) = \text{Cot}^{-1}\left(\frac{(425)/216}{(425)/216}\right) \\
&= \text{Cot}^{-1}(1) = \frac{\pi}{4} = \text{R.H.S}
\end{aligned}$$
