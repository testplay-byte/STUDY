# Page 30 — Unit 08: Inverse Trigonometric Functions and Their Graphs

> 📄 Original scan: [0030.jpg](../../../Raw/Mathematics/Unit-08-Inverse-Trigonometric-Functions-and-Their-Graphs/0030.jpg) · printed page 259

**Example 16:** Evaluate by applying inverse secant addition formula to the expression $\text{Sec}^{-1}\left(\frac{x+2}{x+1}\right) + \text{Sec}^{-1}\left(\frac{x+1}{x}\right)$ and confirm that the result is $\frac{5\pi}{6}$ if $x = 0$.

**Solution:**

$$\begin{aligned}
\text{Sec}^{-1}\left(\frac{x+2}{x+1}\right) + \text{Sec}^{-1}\left(\frac{x+1}{x}\right) &= \text{Cos}^{-1}\left[\frac{1-\sqrt{\left[\left(\frac{x+2}{x+1}\right)^2 - 1\right]\left[\left(\frac{x+1}{x}\right)^2 - 1\right]}}{\left(\frac{x+2}{x+1}\right)\left(\frac{x+1}{x}\right)}\right] = \text{Cos}^{-1}\left[\frac{1-\sqrt{\frac{(x+2)^2-(x+1)^2}{(x+1)^2}\cdot\frac{(x+1)^2-(x)^2}{(x)^2}}}{\left(\frac{x+2}{x+1}\right)\left(\frac{x+1}{x}\right)}\right] \\
&= \text{Cos}^{-1}\left[\frac{1-\frac{\sqrt{(x+2+x+1)(x+2-x-1)(x+1+x)(x+1-x)}}{(x+1)(x)}}{\left(\frac{x+2}{x+1}\right)\left(\frac{x+1}{x}\right)}\right] \\
&= \text{Cos}^{-1}\left[\frac{\frac{x(x+1)-[\sqrt{(2x+3)(2x+1)}]}{(x+1)(x)}}{\left(\frac{x+2}{x+1}\right)\left(\frac{x+1}{x}\right)}\right] = \text{Cos}^{-1}\left[\frac{x(x+1)-[\sqrt{(2x+3)(2x+1)}]}{(x+2)(x+1)}\right]
\end{aligned}$$

At $x = 0$,

$$\text{Sec}^{-1}(2) + \text{Sec}^{-1}(1) = \text{Cos}^{-1}\left[\frac{0-[\sqrt{(3)(1)}]}{(2)(1)}\right] = \text{Cos}^{-1}\left[-\frac{\sqrt{3}}{2}\right] = \frac{5\pi}{6}$$

## Exercise 8.3

1. Establish the identities.

   i. $\text{Sin}^{-1}\left(\frac{1}{3}\right) + \text{Sin}^{-1}\left(\frac{2\sqrt{2}}{3}\right) = \frac{\pi}{2}$
   ii. $\text{Cos}^{-1}\left(\frac{3}{5}\right) + \text{Cos}^{-1}\left(\frac{4}{5}\right) = \frac{\pi}{2}$

   iii. $\text{Tan}^{-1}\left(\frac{3}{4}\right) + \text{Tan}^{-1}\left(\frac{1}{7}\right) = \frac{\pi}{4}$
   iv. $\text{Cot}^{-1}(2 + \sqrt{3}) + \text{Cot}^{-1}(2 - \sqrt{3}) = \frac{\pi}{2}$

   v. $\text{Csc}^{-1}(\sqrt{2}) + \text{Csc}^{-1}(\sqrt{2}) = \frac{\pi}{2}$
   vi. $\text{Sec}^{-1}(2) + \text{Sec}^{-1}(2) = \frac{2\pi}{3}$

   vii. $\text{Sin}^{-1}(x) + \text{Sin}^{-1}(-x) = 0$
   viii. $\text{Cos}^{-1}(x) + \text{Cos}^{-1}(-x) = \pi$

   ix. $\text{Tan}^{-1}\left(\frac{\alpha}{\beta}\right) - \text{Tan}^{-1}\left(\frac{\alpha-\beta}{\alpha+\beta}\right) = \frac{\pi}{4}$
   x. $\text{Cot}^{-1}(1) - \text{Cot}^{-1}(\sqrt{3}) = \frac{\pi}{12}$

   xi. $\text{Csc}^{-1}(\sqrt{2}) - \text{Csc}^{-1}(2) = \frac{\pi}{12}$
   xii. $\text{Cos}^{-1}\left(\frac{1}{2}\right) - \text{Cos}^{-1}\left(\frac{\sqrt{3}}{2}\right) = \frac{\pi}{6}$

2. Evaluate by:

   i. Applying inverse secant addition formula to the expression $\text{Sec}^{-1}\left(\frac{x+1}{x}\right) + \text{Sec}^{-1}\left(\frac{x-1}{x}\right)$ and confirm that the result is $0$ if $x = 0$.

   ii. Applying inverse cosecant addition formula to the expression $\text{Csc}^{-1}\left(\frac{2x+1}{x}\right) + \text{Csc}^{-1}\left(\frac{x+1}{x}\right)$ and confirm that the result is $0$ if $x = 0$.

   iii. Applying inverse cotangent addition formula to the expression $\text{Cot}^{-1}(x - 1) + \text{Cot}^{-1}(2x - 1)$ and confirm that the result is $-\frac{\pi}{4}$ if $x = \pm 1$.
