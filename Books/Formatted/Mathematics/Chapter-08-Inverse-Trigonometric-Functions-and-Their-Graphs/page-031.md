# Page 31 — Unit 08: Inverse Trigonometric Functions and Their Graphs

> 📄 Original scan: [0031.jpg](../../../Raw/Mathematics/Unit-08-Inverse-Trigonometric-Functions-and-Their-Graphs/0031.jpg) · printed page 260

3. Solve the following inverse trigonometric equations algebraically.

i. $\text{Sin}^{-1}(x - 1) = \frac{\pi}{2}$ 
   ii. $\text{Sin}^{-1} x = \text{Cos}^{-1}\left(\frac{5}{13}\right)$ 
   iii. $\text{Tan}^{-1} x = \text{Sin}^{-1}\frac{24}{25}$

iv. $\text{Cos}^{-1}\left(x - \frac{\sqrt{3}}{2}\right) = \frac{\pi}{6}$ 
   v. $\text{Tan}^{-1}\left(x + \frac{\sqrt{2}}{2}\right) = \frac{\pi}{4}$ 
   vi. $\text{Cos}^{-1}\left(x - \frac{1}{2}\right) = \frac{\pi}{3}$

vii. $6 \text{ ArcCot}(2x) - 5\pi = 0$ 
   viii. $9 \text{ ArcSin}^2(x) - \pi^2 = 0$

ix. $\pi - 2 \text{ Sin}^{-1} x = 2\pi$ 
   x. $4 \text{ ArcTan}^2(x) - 3\pi \text{ ArcTan}(x) - \pi^2 = 0$

xi. $\text{Tan}^{-1}\left(\frac{\sqrt{1+\text{Cos}x} + \sqrt{1-\text{Cos}x}}{\sqrt{1+\text{Cos}x} - \sqrt{1-\text{Cos}x}}\right) = \frac{\pi}{4} - \frac{x}{2}, \text{ where } x \in \left(0, \frac{\pi}{2}\right)$

4. Find the values of $x$:

i. $\text{Sin}^{-1}\left(\frac{\sqrt{3}}{2}\right) + \text{Cos}^{-1}(x) = \frac{\pi}{2}$ 
   ii. $\text{Sin}^{-1}\left(\frac{1}{2}\right) + \text{Cos}^{-1}(2x) = \frac{\pi}{6}$

iii. $\text{Sin}^{-1}(x) + \text{Cos}^{-1}\left(\frac{4}{5}\right) = \pi$ 
   iv. $\text{Tan}^{-1}(x) - \text{Tan}^{-1}\left(\frac{1}{x}\right) = \frac{\pi}{4}$

5. Prove that:

i. $\text{Sin}^{-1}\left(\frac{5}{13}\right) - \text{Sin}^{-1}\left(\frac{63}{65}\right) = \text{Cos}^{-1}\left(\frac{3}{5}\right)$ 
   ii. $\text{Sin}^{-1}\left(\frac{8}{17}\right) + \text{Sin}^{-1}\left(\frac{3}{5}\right) = \tan^{-1}\left(\frac{77}{36}\right)$

iii. $\text{Sin}^{-1}\left(\frac{3}{5}\right) + \text{Cos}^{-1}\left(\frac{12}{13}\right) = \text{Sin}^{-1}\left(\frac{56}{65}\right)$ 
   iv. $\text{Tan}^{-1}\left(\frac{1}{4}\right) + \text{Tan}^{-1}\left(\frac{2}{9}\right) = \frac{1}{2}\text{Tan}^{-1}\left(\frac{4}{3}\right)$

v. $\text{Cos}^{-1}\left(\frac{4}{5}\right) + \text{Cos}^{-1}\left(\frac{12}{13}\right) = \text{Cos}^{-1}\left(\frac{33}{65}\right)$ 
   vi. $2\text{Tan}^{-1}\left(\frac{3}{4}\right) - \text{Tan}^{-1}\left(\frac{17}{31}\right) = \frac{\pi}{4}$

vii. $\text{Tan}^{-1}\left(\frac{1}{2}\right) + \text{Tan}^{-1}\left(\frac{1}{5}\right) + \text{Tan}^{-1}\left(\frac{1}{8}\right) = \frac{\pi}{4}$

viii. $\text{Sin}^{-1}\left(\frac{4}{5}\right) + \text{Sin}^{-1}\left(\frac{5}{13}\right) + \text{Sin}^{-1}\left(\frac{16}{65}\right) = \frac{\pi}{2}$

ix. $\text{Tan}^{-1}\left(\frac{3}{4}\right) + \text{Tan}^{-1}\left(\frac{3}{5}\right) - \text{Tan}^{-1}\left(\frac{8}{19}\right) = \frac{\pi}{4}$

x. $2 \text{ Tan}^{-1}\left(\frac{1}{5}\right) + \text{ Sec}^{-1}\left(\frac{5\sqrt{2}}{7}\right) + 2 \text{ Tan}^{-1}\left(\frac{1}{8}\right) = \frac{\pi}{4}$

xi. $\text{Sin}^{-1}(x) + \text{Cos}^{-1}(-x) = \frac{\pi}{2}$ where $-1 < x < 1$
