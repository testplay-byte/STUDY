## 9.1 Trigonometric Equations

A trigonometric equation is a conditional equation that involves trigonometric functions. If it is possible to write the equation in the form:

$$\text{some trigonometric function of } x = \text{a number}$$

$$\text{e.g. } 2\sin x = 1, \quad 2\tan^2 x - 3\tan x + 1 = 0, \quad \cos^{-1}(2x) = \pi$$

We can use the following strategy to solve the equation:

(1) Find all solutions of the equation within one period of the function. This is often done by using properties of the trigonometric function. Quite often, there will be two solutions within a single period.

(2) Use the period of the function to express formulas for all solutions by adding integer multiples of the period to each solution found in the first step. For example, if the function has a period of $2\pi$ and $x_1$ and $x_2$ are the only two solutions in a complete period, then we would write the solutions for the equation as:

$$x = x_1 + k(2\pi), \quad x = x_2 + k(2\pi), \text{ where } k \text{ is an integer.}$$

## STANDARD INTERVALS AND PERIODS FOR ALL SIX TRIGONOMETRIC FUNCTIONS

| S. No. | Trigonometric Function | Principal Interval (One Period) | Period (T) | General Solution Form | Notes |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | $\sin x$ | $[0, 2\pi)$ or $[-\pi, \pi)$ | $2\pi$ | $x=x_i+2\pi k$ | Standard sine wave repeats every $2\pi$ |
| 2 | $\cos x$ | $[0, 2\pi)$ | $2\pi$ | $x=x_i+2\pi k$ | Standard cosine wave repeats every $2\pi$ |
| 3 | $\tan x$ | $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ | $\pi$ | $x=x_i+\pi k$ | Vertical asymptotes at $\pm \frac{\pi}{2}$ |
| 4 | $\cot x$ | $(0, \pi)$ | $\pi$ | $x=x_i+\pi k$ | Asymptotes at $0$ and $\pi$ |
| 5 | $\sec x$ | $[0, \pi) \cup (\pi, 2\pi]$ | $2\pi$ | $x=x_i+2\pi k$ | Excludes $\frac{\pi}{2}+\pi k$ (asymptotes) |
| 6 | $\csc x$ | $(0, \pi) \cup (\pi, 2\pi)$ | $2\pi$ | $x=x_i+2\pi k$ | Excludes $\pi k$ (asymptotes) |

We can use trigonometric identities to help in rewriting the given equation.

**Example 1:** Solve: $4\cos x - 2 = 0$ where $x \in [0, 2\pi]$

**Solution:** $4\cos x - 2 = 0 \Rightarrow 4\cos x = 2$

$$\cos x = \frac{1}{2} > 0 \Rightarrow x \in \text{Quadrant-I or Quadrant-IV with reference angle } \frac{\pi}{3}.$$

$$\begin{aligned}
&\text{Quadrant-I:} && x = \frac{\pi}{3} \\
&\text{Quadrant-IV:} && x = 2\pi - \frac{\pi}{3} = \frac{5\pi}{3}
\end{aligned}$$

Solution set: $\left\{\frac{\pi}{3}, \frac{5\pi}{3}\right\} \in [0, 2\pi]$

**Example 2:** Solve: $\sin x \cos x = \frac{1}{4}$ where $x \in [0, \pi]$

**Solution:** $\sin x \cos x = \frac{1}{4} \Rightarrow 2\sin x \cos x = \frac{1}{2}$

$$\sin 2x = \frac{1}{2} > 0 \Rightarrow 2x \in \text{Quadrant-I or Quadrant-II with reference angle } \frac{\pi}{6}.$$
