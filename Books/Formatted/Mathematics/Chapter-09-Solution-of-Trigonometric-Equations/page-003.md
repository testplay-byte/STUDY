**Example 3:** Solve: $\cot^4 \phi = 4 \csc^2 \phi - 7$ where $\phi \in [0, 2\pi]$

**Solution:**

$$\begin{aligned} \cot^4 \phi &= 4 \csc^2 \phi - 7 && \Rightarrow \cot^4 \phi = 4(1 + \cot^2 \phi) - 7 \\ \cot^4 \phi &= 4 + 4 \cot^2 \phi - 7 && \Rightarrow \cot^4 \phi - 4 \cot^2 \phi + 3 = 0 \\ \cot^4 \phi - \cot^2 \phi - 3 \cot^2 \phi + 3 &= 0 && \Rightarrow \cot^2 \phi (\cot^2 \phi - 1) - 3(\cot^2 \phi - 1) = 0 \\ (\cot^2 \phi - 1)(\cot^2 \phi - 3) &= 0 && \Rightarrow \cot^2 \phi - 1 = 0 \text{ or } \cot^2 \phi - 3 = 0 \\ \cot^2 \phi &= 1 \text{ or } \cot^2 \phi = 3 && \Rightarrow \cot \phi = \pm 1 \text{ or } \cot \phi = \pm \sqrt{3} \\ \tan \phi &= \pm 1 \text{ or } \tan \phi = \pm \frac{1}{\sqrt{3}} \end{aligned}$$

Taking $\tan \phi = 1 > 0 \Rightarrow \phi \in$ Quadrant-I or Quadrant-III with reference angle $\frac{\pi}{4}$.

$$\text{Quadrant-I: } \phi = \frac{\pi}{4} \quad \text{and} \quad \text{Quadrant-III: } \phi = \pi + \frac{\pi}{4} = \frac{5\pi}{4}$$

Taking $\tan \phi = -1 < 0 \Rightarrow \phi \in$ Quadrant-II or Quadrant-IV with reference angle $\frac{\pi}{4}$.

$$\begin{aligned} \text{Quadrant-II: } \phi &= \pi - \frac{\pi}{4} = \frac{3\pi}{4} \\ \text{Quadrant-IV: } \phi &= 2\pi - \frac{\pi}{4} = \frac{7\pi}{4} \end{aligned}$$

Taking $\tan \phi = \frac{1}{\sqrt{3}} > 0 \Rightarrow \phi \in$ Quadrant-I or Quadrant-III with reference angle $\frac{\pi}{6}$.

$$\begin{aligned} \text{Quadrant-I: } \phi &= \frac{\pi}{6} \\ \text{Quadrant-III: } \phi &= \pi + \frac{\pi}{6} = \frac{7\pi}{6} \end{aligned}$$

Taking $\tan \phi = -\frac{1}{\sqrt{3}} < 0 \Rightarrow \phi \in$ Quadrant-II or Quadrant-IV with reference angle $\frac{\pi}{6}$.

$$\begin{aligned} \text{Quadrant-II: } \phi &= \pi - \frac{\pi}{6} = \frac{5\pi}{6} \\ \text{Quadrant-IV: } \phi &= 2\pi - \frac{\pi}{6} = \frac{11\pi}{6} \end{aligned}$$

$$\text{Solution set: } \left\{ \frac{\pi}{4}, \frac{5\pi}{4} \right\} \cup \left\{ \frac{3\pi}{4}, \frac{7\pi}{4} \right\} \cup \left\{ \frac{\pi}{6}, \frac{7\pi}{6} \right\} \cup \left\{ \frac{5\pi}{6}, \frac{11\pi}{6} \right\} \in [0, 2\pi]$$

**Example 4:** Find the general solution of $\csc^3 x + \csc^2 x = 4 \csc x + 4$

**Solution:**

$$\begin{aligned} \csc^3 x + \csc^2 x &= 4 \csc x + 4 && \Rightarrow \csc^3 x + \csc^2 x - 4 \csc x - 4 = 0 \\ \csc^2 x (\csc x + 1) - 4(\csc x + 1) &= 0 && \Rightarrow (\csc x + 1)(\csc^2 x - 4) = 0 \\ \csc x + 1 &= 0 \text{ or } \csc^2 x - 4 = 0 && \Rightarrow \csc x = -1 \text{ or } \csc^2 x = 4 \\ \csc x &= -1 \text{ or } \csc x = \pm 2 && \Rightarrow \sin x = -1 \text{ or } \sin x = \pm \frac{1}{2} \end{aligned}$$

Taking $\sin x = -1 \Rightarrow x = -\frac{\pi}{2}$

Taking $\sin x = \frac{1}{2} > 0 \Rightarrow x \in$ Quadrant-I or Quadrant-II with reference angle $\frac{\pi}{6}$.
