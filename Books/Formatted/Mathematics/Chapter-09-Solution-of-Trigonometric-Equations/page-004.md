# Page 4 — Unit 09: Solution of Trigonometric Equations

> 📄 Original scan: [0004.jpg](../../../Raw/Mathematics/Unit-09-Solution-of-Trigonometric-Equations/0004.jpg) · printed page 265

Quadrant-I: $x = \frac{\pi}{6}$

Quadrant-II: $x = \pi - \frac{\pi}{6} = \frac{5\pi}{6}$

Taking $\sin x = -\frac{1}{2} < 0 \Rightarrow x \in \text{Quadrant-III or Quadrant-IV with reference angle } \frac{\pi}{6}$.

Quadrant-III: $x = \pi + \frac{\pi}{6} = \frac{7\pi}{6}$

Quadrant-IV: $x = 2\pi - \frac{\pi}{6} = \frac{11\pi}{6}$

Since period of sine function is $2\pi$, so the general values of $x$ are as follows:

$x = \frac{\pi}{2} + 2n\pi , \frac{\pi}{6} + 2n\pi , \frac{5\pi}{6} + 2n\pi , \frac{7\pi}{6} + 2n\pi, \frac{11\pi}{6} + 2n\pi$, where $n$ is an integer.

Hence S. $S=\left\{-\frac{\pi}{2}+2n\pi\right\}\cup\left\{\frac{\pi}{6}+2n\pi\right\}\cup\left\{\frac{5\pi}{6}+2n\pi\right\}\cup\left\{\frac{7\pi}{6}+2n\pi\right\}\cup\left\{\frac{11\pi}{6}+2n\pi\right\}$

## Exercise 9.1

1. Solve the trigonometric equations within the domain $[0, 2\pi]$.
   i. $\sqrt{2}\sin x = 1$
   ii. $5\sin x = 2$
   iii. $2\cos\theta + 1 = 0$
   iv. $\cot x + \sqrt{3} = 0$
   v. $\cos x = 0.71$
   vi. $\sqrt{6}\csc x = \sqrt{8}$
   vii. $4\cos x - 3 = 0$
   viii. $\sqrt{2}\csc x + 2 = 0$
   ix. $\tan^2 \rho = 3$

2. Determine the solution over the interval $[0, 2\pi)$.
   i. $\sin 3\theta + \sin\theta = 0$
   ii. $\sin 2\theta = 2\cos\theta$
   iii. $\sin 2\theta + \sin\theta = 0$
   iv. $\cos 2\theta + \cos\theta = 0$
   v. $2\sin^3 \theta = \sin^2 \theta$
   vi. $\cos 2\theta = 3\cos\theta - 2$
   vii. $\cos 3\theta = 2 - \cos\theta$
   viii. $\cos 3\theta = \cos 5\theta$
   ix. $\cos\theta \sin\theta = \frac{1}{2}$
   x. $\cos^2 \theta + 4\sin\theta = 4$
   xi. $\cos \rho - \sqrt{3}\sin \rho = 2$
   xii. $3\tan^2 \theta - 1 = 0$

3. Solve the following trigonometric equations when $\emptyset \in [0, 2\pi]$.
   i. $6\sin\emptyset + 8\cos\emptyset = 7$
   ii. $\cos\emptyset + \cos 3\emptyset = 0$
   iii. $\sin 4\emptyset + \sin 3\emptyset = 0$
   iv. $\sin\emptyset + \sin 3\emptyset = \sin 2\emptyset$
   v. $\tan\emptyset + \cot\emptyset = 8\cos 2\emptyset$
   vi. $\sin 2\emptyset + \sin 3\emptyset + \sin 5\emptyset = 0$
   vii. $5\cos\emptyset + 4 = 2\sin^2 \emptyset$
   viii. $\cos 2\emptyset + 3 = 5\cos\emptyset$
   ix. $\sin^2 \emptyset = 3\cos^2 \emptyset$
   x. $\cos^2 \emptyset - 2\cos\emptyset + 1 = 0$
   xi. $\tan^2 \emptyset - \tan\emptyset = 6$

4. Solve the following trigonometric equations when $x \in [-\pi, \pi]$.
   i. $3\cos x + \sin x = 2$
   ii. $4\cos x + 3\sin x = 2$
   iii. $3\sin x - 2\cos x = 1$
   iv. $\sqrt{3}\cos x + \sin x = \sqrt{2}$
   v. $7\cos x - 6\sin x = 4$
   vi. $4\cos x + 2\sin x = \sqrt{5}$
   vii. $\sec x + 5\tan x + 12 = 0$
   viii. $\sin 2x - \cos x = 0$
   ix. $\cos^2 x - \sin^2 x = 1$
   x. $3\sin^2 x - 2\sin x = 0$

5. Solve the following trigonometric equations for the values of $\theta$ in the range $0^\circ \leq \theta \leq 360^\circ$.
