10. A suspension cable supports a bridge deck and forms a $45^\circ$ angle with the ground. If the deck is 30 meters above the ground, determine the length of the cable needed using the inverse cosine function.

11. At a certain time of day, a 20 meters tall flagpole casts a shadow of 15 meters. If a nearby building casts a shadow of 50 meters at the same time, find the height of the building using the inverse tangent function.

12. An architect is designing a roof with a $20^\circ$ pitch to allow snow to slide off easily. If the width of the building is 12 meters, calculate the rise of the roof using an inverse sine function.

13. The roof of a warehouse needs to be designed with a $30^\circ$ incline to ensure water runoff. If the building is 20 meters wide, determine the rise of the roof using the inverse sine function.

14. A robotic arm in an assembly line needs to reach a point 4 meters away and 3 meters above its base. Find the angle at which the arm should be positioned using the inverse tangent function.

## Review Exercise

**1. Choose the correct answer/solution.**

**i.** If $\sin(2x) = \frac{\sqrt{3}}{2}$ with $x \in [0, 2\pi]$, then value of $x$ is:

$(a)\quad \frac{\pi}{6}, \frac{\pi}{3} \qquad (b)\quad \frac{\pi}{6}, \frac{5\pi}{12} \qquad (c)\quad \frac{\pi}{6}, \frac{5\pi}{6} \qquad (d)\quad \frac{\pi}{6}, \frac{2\pi}{3}$

**ii.** For what value of $x$, a trigonometric equation $\sin x = \cos x$ remains true?

$(a)\quad \frac{\pi}{4}, \frac{3\pi}{4} \qquad (b)\quad \frac{\pi}{4}, \frac{5\pi}{4} \qquad (c)\quad \frac{3\pi}{4}, \frac{5\pi}{4} \qquad (d)\quad \frac{\pi}{4}$

**iii.** Solution set of a trigonometric equation $2\sin x + \sqrt{3} = 0$ in the $4^{\text{th}}$ quadratic is:

$(a)\quad -\frac{\pi}{6} \qquad (b)\quad -\frac{\pi}{3} \qquad (c)\quad -\frac{5\pi}{6} \qquad (d)\quad \frac{11\pi}{6}$

**iv.** If $\cos^2 x = \frac{1}{2}$ with $x \in [0, \pi]$ then value of $x$ is:

$(a)\quad \frac{\pi}{4}, \frac{7\pi}{4} \qquad (b)\quad \frac{\pi}{4}, \frac{3\pi}{4} \qquad (c)\quad \frac{3\pi}{4}, \frac{5\pi}{4} \qquad (d)\quad \frac{5\pi}{4}, \frac{7\pi}{4}$

**v.** What is the solution of $\sec x = 2$, if $x \in [0, \pi]$?

$(a)\quad \left\{-\frac{\pi}{6}\right\} \qquad (b)\quad \left\{-\frac{\pi}{3}\right\} \qquad (c)\quad \left\{\frac{\pi}{3}\right\} \qquad (d)\quad \left\{\frac{\pi}{6}\right\}$

**vi.** What is the solution of $\sin x + \cos x = 0$, if $x \in [0, \pi]$?

$(a)\quad \left\{\frac{\pi}{4}\right\} \qquad (b)\quad \left\{\frac{\pi}{2}\right\} \qquad (c)\quad \left\{\frac{2\pi}{3}\right\} \qquad (d)\quad \left\{\frac{3\pi}{4}\right\}$

**vii** One solution of a trigonometric equation $\cos x + \sin x = \sqrt{2}$, if $x \in [0, 2\pi]$?

$(a)\quad \left\{\frac{\pi}{4}\right\} \qquad (b)\quad \left\{-\frac{\pi}{4}\right\} \qquad (c)\quad \left\{\frac{2\pi}{4}\right\} \qquad (d)\quad \left\{\frac{3\pi}{2}\right\}$
