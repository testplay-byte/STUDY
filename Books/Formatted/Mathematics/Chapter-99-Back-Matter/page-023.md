# Page 23 — Glossary

> 📄 Original scan: [0023.jpg](../../../Raw/Mathematics/Back-Matter/0023.jpg) · printed page 312

**Normal line:** A line which is perpendicular to the tangent line at the point of tangency is called the normal line at that point.

**Numerical integration:** It is the approximate computation of an integral using numerical techniques.

**One to One function:** A function $f\colon \text{A} \to \text{B}$ is one-to-one if distinct elements of set A have distinct images in set B.

**Onto function:** A function $f\colon \text{A} \to \text{B}$ is said to be an into function if $\text{rang}(f) = \text{B}$.

**Ordinary differential equation:** If in a differential equation, only one independent variable is involved, the equation is called an ordinary differential equation.

**Parabola:** It is the set of all the points in the plane which are equidistant from a fixed point (focus) and a fixed line in the plane (directrix).

**Particular solution of DE:** The solution free from arbitrary constants is called a particular solution of a DE.

**Period of a trigonometric function:** It is the distance between two repeating points on the graph, or the time it takes to complete one full cycle.

**Point of concurrency:** The point of intersection of three or more lines is known as the “point of concurrency.”

**Point of inflection:** The point where the function is neither concave nor convex is known as the point of inflection.

**Power function:** The power functions are of the form $f(x) = k x^a$, where ‘k’ and ‘a’ are any real numbers.

**Principal trigonometric function:** The principal trigonometric function is just the trigonometric function with a restricted domain.

**Quadratic function:** The function is of the form, $y = ax^2 + bx + c$; $a, b, c \in R \wedge a \neq 0$ is called quadratic.

**Range of function:** The set of all the outputs of a function is known as the range of the function.

**Rational function:** A function that is composed of two functions and expressed in the form of a fraction is a rational function.

**Regula Falsi method:** It is a numerical technique used to find the roots of a non-linear equation.

**Relative maximum:** A number $f(c_1)$ is a relative maximum of a function $f$ if $f(x) \leq f(c_1)$ but every $\dot{x}$ in some open interval that contains $c_1$.

**Relative minimum:** A number $f(c_1)$ is a relative minimum of a function $f$ if $f(x) \geq f(c_1)$ for every $x$ in some open interval that contains $c_1$.

**Roots or Zeros:** The roots (or zeros) of an equation are the values of x that make the function equal to zero.

**Scalar valued function:** A function from a vector to some constant is known as scalar valued function.

**Second derivative test for relative extrema:** Let $f$ be function for which $f''$ exists on an interval $(a, b)$ that contains the critical number.
(i) If $f''(c) > 0$, then $f(c)$ is a relative minimum. (ii) If $f''(c) < 0$, then $f(c)$ is a relative maximum.

**Second order differential equation:** The equation which includes the second-order derivative is called the second-order differential equation.

**Separable differential equation:** A first order differential equation of the form $dy/dx = f(x)g(x)$ where $f$ is the function of $x$ only and $g$ is the function of $y$ only, is said to be separable or to have separable variables.

**Simpson's 1/3rd rule:** It is an extension of the trapezoidal rule in which the integrand is approximated by a second-order polynomial.

**Slope of tangent:** Derivative at point of the curve is the slope of the tangent line to the curve at that point.

**Square root function:** The function of the form $y = \sqrt{x}$ , where $x \geq 0$ is called a square root function.

**Transcendental function:** The functions which are not algebraic are called transcendental.

**Transverse axis of hyperbola:** The axis which passes through both the foci of hyperbola is called the transverse axis.

**Trapezoidal rule:** It is a technique for numerical integration, i.e., approximating the definite integral.

**Trigonometric equation:** A trigonometric equation is a conditional equation that involves trigonometric functions.

**Vector valued function:** A vector valued function is a function where the domain is the subset of real numbers and the range is a vector.

**Vertex of parabola:** The point where the parabola cuts its axis is called vertex of the parabola.

**Vertical shift:** A vertical shift adds/subtracts a positive constant to/from every y-coordinate while leaving the x-coordinate unchanged.

**Vertices of ellipse:** The points where the ellipse cut its major axis are known as the vertices of ellipse.

**Vertices of hyperbola:** The points where the hyperbola cut its focal axis are known as the vertices of the hyperbola.
