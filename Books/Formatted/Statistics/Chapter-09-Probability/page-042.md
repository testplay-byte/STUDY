# Page 42 — Probability (Chapter 9) — Multiple-Choice Questions

> 📄 Original scan: [0042.jpg](../../../Raw/Statistics/Chapter-09-Probability/0042.jpg) · printed page 52

101. The conditional probability P( A / B ) is not defined if P( B ) = ________.
    - (a) 1
    - (b) 0
    - (c) 0.5
    - (d) 0.25

102. The conditional probability of the event A when event B has occurred is denoted by:
    - (a) $P(A + B)$
    - (b) $P(A - B)$
    - (c) $P(A/B)$
    - (d) $P(\bar{A})$

103. If A and B are any two events, then $P(\bar{A}/B)$ is equal to:
    - (a) $P(A/B)$
    - (b) $1 - P(A/B)$
    - (c) $1 + P(A/B)$
    - (d) $P(\bar{A} \cap B)$

104. If A and B are two not-independent events, then the probability that both A and B will happen together is:
    - (a) $P(A \cap B) = P(A).P(B/A)$
    - (b) $P(A \cap B) = P(A) P(B)$
    - (c) $P(A \cap B) = P(A) + P(B)$
    - (d) $P(A \cap B) = P(A)$

105. If A and B are two dependent events, then:
    - (a) $P(A) P(B/A) = P(B) P(A/B)$
    - (b) $P(A/B) = P(B/A)$
    - (c) $P(A/B) = P(A)$
    - (d) $P(A) = P(B)$.

106. If A and B are any two events, then $P(A/B) + P(\bar{A}/B)$ is equal to:
    - (a) 0
    - (b) 0.25
    - (c) 0.5
    - (d) 1

107. If A is an arbitrary event, then P( A / A ) is equal to:
    - (a) zero
    - (b) one
    - (c) infinity
    - (d) less than one

108. If P( B/A ) = 0.50 and P( A ∩ B ) = 0.40, then P( A ) will be equal to:
    - (a) 0.40
    - (b) 0.50
    - (c) 0.80
    - (d) 1

109. If P( A/B ) = P( A ) and P( B/A ) = P( B ), then A and B are:
    - (a) mutually exclusive
    - (b) dependent
    - (c) equally likely
    - (d) independent

110. Two coins are tossed. Probability of getting two heads given that there is at least one head is given by:
    - (a) 1/2
    - (b) 1/3
    - (c) 1/4
    - (d) 2/3

111. A fair die is rolled. Probability of getting even face given that face is less than 5 is given by:
    - (a) 1/2
    - (b) 5
    - (c) 2
    - (d) 6

112. Two dice are rolled. Probability of getting a total of 4 given that both faces are similar is:
    - (a) 5/36
    - (b) 1/36
    - (c) 4/36
    - (d) 1/6
