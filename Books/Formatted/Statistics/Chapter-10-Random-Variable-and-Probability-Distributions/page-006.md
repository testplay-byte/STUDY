## 10.6.DISCRETE RANDOM VARIABLE

A random variable X is called discrete if it can assume finite or countably infinite number of values. If two bulbs are selected from a certain lot, the number of defective bulbs may be 0, 1 or 2. The range of the variable is from 0 to 2 and random variable can take some selected values in this range. The number of defective bulbs cannot be 1.1 or $-1$ or 3 etc. This random variable can take only the specific values which are 0, 1 and 2. When two dice are rolled the total on the two dice will be 2, 3, ..., 12. The total on the two dice is a discrete random variable.

## 10.7.DISCRETE PROBABILITY DISTRIBUTION

Suppose a discrete random variable X can assume the values $x_1$, $x_2$, $x_3$, ... , $x_n$ with corresponding probabilities $p(x_1)$, $p(x_2)$, $p(x_3)$, ... , $p(x_n)$. The set of ordered pairs $[x_1, p(x_1)]$, $[x_2, p(x_2)]$, $[x_3, p(x_3)]$, ... , $[x_n, p(x_n)]$ is called the probability distribution or probability function of random variable X. A probability distribution can be presented in a tabular form showing the values of the random variable X and the corresponding probabilities denoted by $p(x_i)$ or $f(x_i)$. The above information can be collected in the form of a table below called the probability distribution of the random variable X. The probability that random variable X will take the value $x_i$ is denoted by $p(x_i)$ where $p(x_i) = \text{P}(X = x_i)$

| Values of random variable ($x_i$) | $x_1$ | $x_2$ | $x_3$ | ... | $x_i$ | ... | $x_n$ |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Probability $p(x_i)$ | $p(x_1)$ | $p(x_2)$ | $p(x_3)$ | ... | $p(x_i)$ | ... | $p(x_n)$ |

The probability of some interval can be calculated by adding the probabilities of all the points in the interval. For example $\text{P}[ x_1 < \text{X} < x_4 ] = \text{P}(\text{X} = x_2) + \text{P}(\text{X} = x_3)$.

This type of addition will not be possible in continuous random variable for finding the probability of an interval. Therein we shall use the integral calculus for finding the probability of an interval.

The probability distribution can also be described in the form of an equation for $f(x_i)$ with a list of possible values of the random variable X. Some probability distributions in the form of equations are

(i) $\quad f(x) = p(x) = \frac{1}{6}$ for $x = 1, 2, 3, 4, 5, 6.$

For each value of x, the probability is 1/6. It is the probability distribution when a fair die is rolled.

(ii) $\quad f(x) = p(x) = \binom{3}{x} \left( \frac{1}{2} \right)^3$ for $x = 0, 1, 2, 3.$

It is the probability distribution when three fair coins are tossed.

(iii) $\quad f(x) = p(x) = \frac{6 - |7 - x|}{36}$ for $x = 2, 3, 4, \ldots, 12.$

It is the probability distribution of the sum of spots when a pair of dice is thrown.

## 10.8.PROPERTIES OF THE DISCRETE PROBABILITY FUNCTION

A discrete probability distribution or function f(x) or p(x) has the following properties.

(i) $\quad f(x)$ is always non-negative. It lies between 0 and 1. Thus $0 \leq f(x) \leq 1$

(ii) $\quad$ The sum of all the probabilities is 1 that is $\sum f(x) = 1$

## 10.9.GRAPH OF THE DISCRETE PROBABILITY FUNCTION

The discrete probability distribution can be presented in the form of a graph by taking the values $x_1, x_2, x_3, \ldots, x_i, \ldots$ on X-axis and drawing vertical lines of heights equal to $f(x_1), f(x_2), f(x_3), \ldots, f(x_i), \ldots$ on Y-axis. This type of graph is called line graph.
