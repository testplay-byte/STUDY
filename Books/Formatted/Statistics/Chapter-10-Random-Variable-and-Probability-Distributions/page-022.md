## SHORT DEFINITIONS

**1. Random Numbers**

Random numbers are numbers that occur in a sequence such that the values are uniformly distributed over a defined interval or set and it is impossible to predict future values based on past or present ones. *or*

Random numbers are numbers obtained by some random process from a discrete uniform distribution of ten basic digits which are used for counting purpose. These digits are 0, 1, 2, 3, ...., 9. We can make numbers of any size with the help of these digits. So that each of these digits has an equal chance of $1/10$ of being selected.

**2. Generation of Random Numbers**

Random numbers can be generated manually by drawing numbered cards, slips of papers, spinning numbered wheels or rotating. These numbers can be generated mechanically by use of calculators and computers.

**3. Application of Random Numbers**

Random numbers are useful in the selection of a simple random sample from a given finite population. Whenever we want to select a sample is such a way that it is not based on our personal judgement, we can take help of the random numbers to select such a sample.

**4. Random Variable**

A random variable is a numerical quantity whose value depends on chance. *or*

A rule that assigns a numerical value to each outcome of a sample space is called random variable.

**5. Examples of Random Variable**

Some examples of the random variable are:

(i) The number of errors per page of a balance sheet.
(ii) The weight of rice in kilograms produced per acre.
(iii) The height ( in cm. ) of a player on a basketball team.
(iv) The blood serum cholesterol level of a person.
(v) A countable number of values.

**6. Probability Distribution**

A probability distribution gives the probability for each value of the random variable. *or*

A list containing both the values of the random variable and their corresponding probabilities is called the probability distribution of the random variable.

**7. Types of Random Variable**

**(i) Discrete random variable:** A variable if it can take only some selected values in a given interval.

**(ii) Continuous random variable:** A variable which can theoretically assume any value between two given values.

**8. Discrete Sample Space**

A sample space is called a discrete sample space if it contains a finite or countable number of sample points.

**9. Discrete Random Variable**

A discrete random variable is one which can assume any set of possible values which can be counted or listed. *or*

When the values of the random variable are countable, it is called a discrete random variable.

**10. Examples of Discrete Random Variable**

Some examples of the discrete random variable are:

(i) The number of houses in a certain town.
(ii). The number of plots sold at a dealership during a given week.
(iii) The number of complaints received at the office of PTCL on a given day.
(iv) The number of tails obtained in four tosses of a coin.
(v) The number of customers who visit a super store during any given period.

**11. Discrete Probability Distribution**

A probability distribution is called a discrete probability distribution if it refers to a discrete sample space. *or*

The lists of all the possible values that the random variable can assume and their corresponding probabilities is called discrete probability distribution.
