## 12. Probability Function

A function denoted by $f(x)$ that can provide the probability for each value of the discrete random variable is called a probability function. *or*

A probability function is a correspondence that assigns probabilities to the values of a random variable.

## 13. Discrete Probability Function

A discrete probability function is a mutually exclusive listing of all possible numerical outcomes for that random variable such that a particular probability of occurrence is associated with each outcome.

## 14. Properties of the Discrete Probability Function

The probability function for a discrete random variable must have the following two properties:

(i) The range of $f(x)$ is the set of real numbers from 0 to 1, inclusive. That is $0 \leq f(x) \leq 1$.

(ii) The sum of the probabilities assigned to the values of a random variable must be equal to one, that is $\sum f(x) = 1$.

## 15. Probability Mass Function

The probability mass function of the discrete random variable X gives the probabilities associated with all of the outcomes $x$ of the random variable. These probabilities are written as $P(X = x)$ or just $p(x)$ or $f(x)$ and can be represented in a table, a bar chart or by a formula. *or*

A probability mass function for a discrete random variable is any representation of the values of a discrete random variable and the associated probabilities.

## 16. Properties of Probability Mass Function

Properties of probability mass function are:-

(i) $f(x)$ or $p(x)$ is always non-negative. It lies between 0 and 1 (inclusive). Thus $0 \leq p(x) \leq 1$.

(ii) The sum of all the probabilities is one that is $\sum f(x) = 1$.

## 17. Mathematical Expectation or Expected Value

We multiply each possible value of $x$ by its probability $p(x)$ and then we sum this product over all possible values of $x$ that is

$$E(X) = \sum xp(x). \quad \text{or}$$

Suppose a random variable X takes $n$ values as $x_1, x_2, x_3, \ldots, x_n$ with corresponding probabilities $p(x_1), p(x_2), p(x_3), \ldots, p(x_n)$. The mathematical expectation of the random variable X is equal to the sum of the products of each value of $x$ and the corresponding value $p(x)$ that is

$$\begin{aligned} E(X) &= x_1p(x_1) + x_2p(x_2) + x_3p(x_3) + \ldots + x_np(x_n) \\ &= \sum xp(x), \text{ if } x \text{ is a discrete random variable}. \end{aligned}$$

$$E(X) = \int_{-\infty}^{\infty} xp(x)dx, \text{ if } x \text{ is a continuous}$$

random variable and $p(x)$ is the value of its probability density at $x$.

## 18. Properties of Mathematical Expectation or Laws of Expectation

(i) $E(\text{Constant}) = \text{Constant}$

(ii) $E(aX) = aE(X)$, if a is a constant but $a \neq 0$.

(iii) $E(X + a) = E(X) + a$, if a is a constant.

(iv) $E(aX + b) = aE(X) + b$, if a and b are constants and $a \neq 0$. If $a = 0$, then $E(b) = b$. If $b = 0$, then $E(aX) = aE(X)$.

(v) $E(X \pm Y) = E(X) \pm E(Y)$

(vi) $E(XY) = E(X)E(Y)$, if X and Y are independent random variables.

(vii) $E[X - E(X)] = 0$

## 19. Continuous Sample Space

If the sample space of an experiment is the real line or intervals on the real line, we call it continuous.

## 20. Continuous Random Variable

A continuous random variable is one which can assume an infinite spectrum of different values across an interval and which cannot be counted or listed. *or*

A variable that can assume any possible value between two points is called a continuous random variable.
