## 21. Examples of Continuous Random Variable
Some examples of continuous random variable are:
(i) The price of a car.
(ii) The weight of a person.
(iii) The length of a bridge.
(iv) The life time of a electric bulb.
(v) The area of an office.

## 22. Probability Density Function
A probability density function is a formula, or equation, used to represent the probability distribution of a continuous random variable.

*or*

The function that defines the probability distribution of a continuous random variable is called probability density function.

## 23. Properties of Probability Density Function
The probability density function $f(x)$ or $p(x)$ must have the following properties:
(i) It is non-negative that is $f(x) \geq 0$ for all $x$
(ii) Total Area $= \int_{-\infty}^{\infty} f(x)dx = 1$
(iii) $P(X = C) = \int_{C}^{C} f(x)dx = 0$, where $C$ is a constant.

## 24. Distribution Function
The distribution function gives the probability of the event that random variable $X$ takes a value less than or equal to a specified value $x$. The distribution function is denoted by $F(x)$. Mathematically, it is denoted by

$F(x) = P(X \leq x)$. The distribution function (d.f) is also called cumulative distribution function (cdf) of the random variable $X$. The distribution function is therefore related to a continuous probability density function $p(x)$.

## 25. Properties of Distribution Function
The distribution function $F(x)$ have the following properties:
(i) $F'(x) = f(x) \geq 0$, so that $F(x)$ is non-decreasing function.
(ii) $F(-\infty) = P(\phi) = 0$ and $F(+\infty) = P(S) = 1$
