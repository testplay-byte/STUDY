**Q.18** Write down the formula for the probability distribution of the sum of spots when a pair of dice is thrown.

**Ans.** $p(x) = (6 - |7 - x|)/36$ for $x = 2, 3, 4, \ldots,12$.

**Q.19** What would be the probability distribution for the outcomes associated with the throw of a fair six-sided die?

| x | 1 | 2 | 3 | 4 | 5 | 6 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |

**Q.20** Three coins are tossed if x = number of tails, then make the probability distribution of x.

**Ans.**

| x | 0 | 1 | 2 | 3 | Total |
| :--- | :--- | :--- | :--- | :--- | :--- |

**Q.21** Two coins are tossed, if x = number of heads, then make the probability distribution of x.

**Ans.**

| x | 0 | 1 | 2 | Total |
| :--- | :--- | :--- | :--- | :--- |
| p(x) | 1/4 | 2/4 | 1/4 | 1 |

**Q.22** Given Head : Tail = 4 : 2. Find P( Head ) and P( Tail ).

**Ans.** P( Head ) = 2/3 and P( Tail ) = 1/3

**Q.23** Given $f( x ) = x/10$ and $x = 1, 2, 3, 4$. Show that f(x) is a probability function.

**Ans.** $\sum f( x ) = 1$

**Q.24** Given $x = 0, 1, 2$ and $p(x) = 5/8, 4/8, 1/8$. Is this probability distribution?

**Ans.** No because $\sum p(x) = 1.25$

**Q.25** Given $x = -1, 0, 1$ and $p(x) = (2x + 3)/4$. Whether this is a probability distribution or not?

**Ans.** No because $\sum p(x) = 2.25$

**Q.26** Check whether the following function is a probability distribution or not, why?
$f(y) = 1/4$ for $y = 1, 2, 3, 4, 5$.

**Ans.** Since the sum of probabilities is one that is $\sum f( y ) = 1$. But in this case $\sum f( y ) = 1.25$ which is not possible. Hence this is not a probability distribution.

**Q.27** Given $x = 1, 2, 3, 4, 5$ and $p(x) = 1/10, 3/10, p, 2/10, 1/10$. Find the value of p.

**Ans.** $3/10$

**Q.29** Given $x = 0, 1, 2$ and $p( x ) = 4C, 3C, C$. Find the value of C.

**Q.30** Given $f(x) = k/x$ and $x = 1, 2, 3$. Find k.

**Q.31** Given $p(x) = k \binom{4}{x}$ and $x = 0, 1, 2, 3, 4$. Find the value of k.

**Q.32** Given $x = - 10, - 20, 30$ and $p(x) = 2k, 3k, 5k$. Find $P(X < 30)$.

**Ans.** $0.5$

**Q.33** Given $x = -1, 0, 1, 2$ and $p(x) = k|x - 2|$. Find $P(X=0)$.

**Ans.** $1/3$

**Q.34** Given $x = - 3, - 2, 2, 3$ and $p(x) = c, 4c; 3c, 2c$. Find $P(X > -3)$.

**Ans.** $0.9$
