**Example 12.4.**

Given a normal distribution with $\mu = 40$ and $\sigma = 6$, find

(a) the area below 32 (b) the area above 27 (c) the area between 42 and 51.

**Solution:** Here, $\mu = 40$, $\sigma = 6$ and $Z = \frac{X - \mu}{\sigma} = \frac{X - 40}{6}$. Therefore

(a) $Z = \frac{32 - 40}{6} = -\frac{8}{6} = -1.33$

$P( X < 32 ) = P( Z < -1.33 )$

$= P( -\infty \leq Z \leq 0 ) - P( -1.33 \leq Z \leq 0 )$

$= 0.5 - 0.4082 = 0.0918$

[Figure F3]

(b) $Z = \frac{27 - 40}{6} = -\frac{13}{6} = -2.17$

$P( X > 27 ) = P( Z > -2.17 )$

$= P( -2.17 \leq Z \leq 0 ) + P( 0 \leq Z \leq \infty )$

$= 0.4850 + 0.5 = 0.9850$

[Figure F4]

(c) $Z_1 = \frac{X_1 - 40}{6} = \frac{42 - 40}{6} = \frac{2}{6} = 0.33$

$Z_2 = \frac{X_2 - 40}{6} = \frac{51 - 40}{6} = \frac{11}{6} = 1.83$

$P( 42 \leq X \leq 51 ) = P( 0.33 \leq Z \leq 1.83 )$

$= P( 0 \leq Z \leq 1.83 ) - P( 0 \leq Z \leq 0.33 )$

$= 0.4664 - 0.1293 = 0.3371$
