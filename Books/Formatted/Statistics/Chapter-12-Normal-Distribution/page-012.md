**Example 12.14.**

A machine produces bolts which are 10% defective. Find the probability that in a random sample of 400 bolts produced by this machine (i) at most 30 (ii) between 30 and 50 ( both exclusive ) (iii) between 35 and 45 (both inclusive) (iv) at least 55 bolts will be defective.

**Solution:** Here, n = 400, p = 0.10, q = 1 - p = 1 - 0.10 = 0.90, $\mu = np = 400 ( 0.10 ) = 40$,

$\sigma = \sqrt{npq} = \sqrt{400(0.10)(0.90)} = 6$ and $Z = \frac{X - \mu}{\sigma} = \frac{X - 40}{6}$. Therefore

(i) Considering the data as continuous, it follows that at most 30 bolts will be defective can be considered as at most 30.5 bolts will be defective. The corresponding Z value is

$Z = \frac{30.5 - 40}{6} = -1.58$

$P(X \leq 30) = P(Z \leq -1.58) = P(-\infty \leq Z \leq 0) - P(-1.58 \leq Z \leq 0) = 0.5 - 0.4429 = 0.0571$

(ii) Considering the data as continuous, it follows that between 30 and 50 defective bolts can be considered as between 30.5 and 49.5 defective bolts. The corresponding Z values are

$Z_1 = \frac{X_1 - 40}{6} = \frac{30.5 - 40}{6} = -1.58$ and $Z_2 = \frac{X_2 - 40}{6} = \frac{49.5 - 40}{6} = +1.58$

$P(30 < X < 50) = P(-1.58 \leq Z \leq +1.58) = P(-1.58 \leq Z \leq 0) + P(0 \leq Z \leq 1.58) = 0.4429 + 0.4429 = 0.8858$

(iii) Considering the data as continuous, it follows that between 35 and 45 defective bolts can be considered as between 34.5 and 45.5 defective bolts. The corresponding Z values are

$Z_1 = \frac{X_1 - 40}{6} = \frac{34.5 - 40}{6} = -0.92$ and $Z_2 = \frac{X_2 - 40}{6} = \frac{45.5 - 40}{6} = +0.92$

$P(35 \leq X \leq 45) = P(-0.92 \leq Z \leq +0.92) = P(-0.92 \leq Z \leq 0) + P(0 \leq Z \leq 0.92) = 0.3212 + 0.3212 = 0.6424.$

(iv) Considering the data as continuous, it follows that at least 55 bolts will be defective can be considered as at least 54.5 bolts will be defective. The corresponding Z value is

$Z = \frac{54.5 - 40}{6} = 2.42$

$P(X \geq 55) = P(Z \geq 2.42) = P(0 \leq Z \leq \infty) - P(0 \leq Z \leq 2.42) = 0.5 - 0.4922 = 0.0078$
