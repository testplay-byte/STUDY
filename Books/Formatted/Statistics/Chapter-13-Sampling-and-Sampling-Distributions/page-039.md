**96.** If $s^2 = \frac{\sum(X - \bar{X})^2}{n - 1}$ and sampling is done with replacement, then $E(s^2)$ is equal to:

(a) $\sigma^2$ (b) $\frac{\sigma^2}{n}$ (c) $\sqrt{\frac{\sigma^2}{n}}$ (d) $\left(\frac{n-1}{n}\right)\sigma^2$

**97.** In sampling without replacement, $\mu_{s^2}$ is equal to:

(a) $\left(\frac{N-1}{N}\right)\sigma^2$ (b) $\left(\frac{N}{N-1}\right)\sigma^2$ (c) $\left(\frac{N}{N-1}\right)\left(\frac{n-1}{n}\right)\sigma^2$ (d) $\left(\frac{n-1}{n}\right)\sigma^2$

**98.** If X represent the number of units having the specified characteristic and n is the size of the sample, then sample proportion $\hat{p}$ is equal to:

(a) $\frac{n}{X}$ (b) $\frac{X}{n}$ (c) $\frac{X+\sigma}{n}$ (d) $\frac{\sigma}{\sqrt{n}}$

**99.** If X represent the number of units having the specified characteristic and N is the size of the population, then population proportion p is equal to:

(a) $\frac{X}{n}$ (b) $\frac{N}{X}$ (c) $\frac{X}{N}$ (d) $\frac{\sigma^2}{N}$

**100.** In sampling with replacement, standard error of the sample proportion $\hat{p}$ is equal to:

(a) $\frac{p(1-p)}{n}$ (b) $\sqrt{\frac{p(1-p)}{n}}$ (c) $\sqrt{\frac{p+q}{2}}$ (d) $\sqrt{\frac{p(1-p)}{n} \left(\frac{N-n}{N-1}\right)}$

**101.** In sampling without replacement, the standard error of sampling distribution of sample proportion $\hat{p}$ is equal to:

(a) $pq \left(\frac{N-n}{N-1}\right)$ (b) $\frac{pq}{n} \left(\frac{N-n}{N-1}\right)$ (c) $\sqrt{\frac{pq}{n} \left(\frac{N-n}{N-1}\right)}$ (d) $\frac{\sqrt{pq}}{n} \left(\frac{N-n}{N-1}\right)$

**102.** If $E(\hat{p}) = 3/5$, then the value of population proportion is:

(a) $2/5$ (b) $3/5$ (c) $5/3$ (d) $1/5$

**103.** When sampling is done with or without replacement, $E(\hat{p}_1 - \hat{p}_2)$ is equal to:

(a) $\hat{p}_1 - \hat{p}_2$ (b) $p_1 - p_2$ (c) $p_1 + p_2$ (d) $p_1 p_2$

**104.** In case of sampling with replacement $\sigma_{\hat{p}_1 - \hat{p}_2}$ is equal to:

(a) $\sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}$ (b) $\sqrt{\frac{pq}{n}}$ (c) $\sqrt{\frac{p_1 q_1}{n_1} + \frac{p_2 q_2}{n_2}}$ (d) $\sqrt{p_1 q_1 + p_2 q_2}$

**105.** If $p_1 = p_2 = p$ and $n_1 \neq n_2$, then S.E $(\hat{p}_1 - \hat{p}_2)$ is equal to:

(a) $\frac{p_1 q_1}{n_1} + \frac{p_2 q_2}{n_2}$ (b) $\frac{p_1 q_1}{n_1} - \frac{p_2 q_2}{n_2}$ (c) $\sqrt{\frac{p_1 q_1}{n_1} + \frac{p_2 q_2}{n_2}}$ (d) $\sqrt{pq \left(\frac{1}{n_1} + \frac{1}{n_2}\right)}$
