**Q.79** Write the formulas of biased and unbiased sample variances.

**Q.80** Describe the relations of the sampling distribution of $S^2 = \frac{\sum(X - \bar{X})^2}{n}$ and $s^2 = \frac{\sum(X - \bar{X})^2}{n - 1}$.

**Q.81** Given $\mu = 6$, $n = 2$ and $\sigma^2 = 10.8$. Find $E(S^2)$.

**Ans.** 5.4

**Q.82** Given $N = 7$, $n = 2$ and $\sigma^2 = 16$. If sampling is done without replacement, then find $E(S^2)$.

**Ans.** 9.3333

**Q.83** Given $N = 7$, $n = 2$ and $\sigma^2 = 16$. If sampling is done without replacement, then find $\mu_{s^2}$ where $s^2 = \frac{\sum(X - \bar{X})^2}{n - 1}$.

**Ans.** 18.67

**Q.84** Given $\mu = 6$, $n = 2$ and $\sigma^2 = 10.8$. Find $E(s^2)$ where $s^2 = \frac{\sum(X - \bar{X})^2}{n - 1}$

**Ans.** 10.8

**Q.85** Given $N = 5$, $n = 2$ and $E(S^2) = 5$ where $S^2 = \frac{\sum(X - \bar{X})^2}{n}$. Find $\sigma^2$ when sampling is done without replacement.

**Ans.** 8

**Q.86** Given $N = 10$, $n = 5$ and $E(S^2) = 80$ where $S^2 = \frac{\sum(X - \bar{X})^2}{n}$. If sampling is done with replacement, then find $\sigma$.

**Ans.** 10

**Q.87** Given $N = 8$, $n = 3$ and $E(s^2) = 4$ where $s^2 = \frac{\sum(X - \bar{X})^2}{n - 1}$. Find $\sigma^2$ when sampling is done without replacement.

**Ans.** 3.5

**Q.88** Given $N = 3$, $n = 2$, $E(s^2) = 9$ where $s^2 = \frac{\sum(X - \bar{X})^2}{n - 1}$. If sampling is done with replacement, then find $\sigma$.

**Ans.** 3

**Q.89** Describe the properties of the sampling distribution of difference between two means.

**Q.90** Given $n_1 = 30$, $n_2 = 50$, $\sigma_1^2 = 150$, $\sigma_2^2 = 200$, $\mu_1 = 78$ and $\mu_2 = 75$. Find $\mu_{\bar{x}_1 - \bar{x}_2}$ and $\sigma_{\bar{x}_1 - \bar{x}_2}$

**Ans.** 3 and 3.

**Q.91** Given $n_1 = 30$, $n_2 = 25$, $\sigma_1^2 = 300$ and $\sigma_2^2 = 150$. Find $\sigma_{\bar{X}_1 - \bar{X}_2}^2$.

**Ans.** 16

**Q.92** Given $N_1 = 3$, $n_1 = 2$, $N_2 = 4$, $n_2 = 2$, $\sigma_1^2 = 8/3$ and $\sigma_2^2 = 5/4$. If sampling is done without replacement, then find the value of $\sigma_{\bar{X}_1 - \bar{X}_2}^2$ or Var $(\bar{X}_1 - \bar{X}_2)$.

**Ans.** 1.0833

**Q.93** Define the sampling distribution of sample proportion and describe its properties.
