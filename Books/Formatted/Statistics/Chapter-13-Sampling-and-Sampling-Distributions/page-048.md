**Q.41** Let $\hat{p}_1$ represent the proportion of even numbers in a random sample of size $n_1 = 2$ with replacement from a finite population consisting of values 0, 4 and 5. Similarly, let $\hat{p}_2$ represent the proportion of odd numbers in a random sample of size $n_2 = 2$ with replacement from another finite population consisting of values 3 and 4. Form a sampling distribution of $(\hat{p}_1 - \hat{p}_2)$. Verify that:

(i) $\mu_{\hat{p}_1 - \hat{p}_2} = p_1 - p_2$ (ii) $\sigma_{\hat{p}_1 - \hat{p}_2} = \sqrt{\frac{p_1q_1}{n_1} + \frac{p_2q_2}{n_2}}$

**Ans:** $\mu_{\hat{p}_1 - \hat{p}_2} = 1/6$, $\sigma_{\hat{p}_1 - \hat{p}_2} = 0.49$, $p_1 = 1/3$, $p_2 = 1/2$

**Q.42** (i) Given $p_1 = 2/3$, $n_1 = 2$, $p_2 = 1/2$ and $n_2 = 2$. Find $\sigma^2_{\hat{p}_1 - \hat{p}_2}$ or Var $(\hat{p}_1 - \hat{p}_2)$.

(ii) Given $N_1 = 4$, $n_1 = 2$, $N_2 = 4$, $n_2 = 2$, $p_1 = 1/2$ and $p_2 = 1/4$. If sampling is done without replacement, find S.E. $(\hat{p}_1 - \hat{p}_2)$.

**Ans:** (i) 0.2361 (ii) 0.3819

**Q.43** (i) Given $N_1 = 6$, $n_1 = 3$, $X_1 = 3$, $N_2 = 5$, $n_2 = 2$ and $X_2 = 2$. Find Var $(\hat{p}_1 - \hat{p}_2)$ if sampling is done without replacement.

(ii) Given $N_1 = 3$, $n_1 = 2$, $p_1 = 1/2$, $N_2 = 3$, $n_2 = 2$ and $p_2 = 1/3$. Find S.E $(\hat{p}_1 - \hat{p}_2)$ if sampling is done with replacement.

**Ans:** (i) 0.14 (ii) 0.4859
