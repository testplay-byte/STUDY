**Q.26** Determine the critical value of Z in each of the following circumstances:
(a) $1 - \alpha = 0.90$   (b) $1 - \alpha = 0.92$
(c) $1 - \alpha = 0.94$   (d) $1 - \alpha = 0.96$
(e) $1 - \alpha = 0.98$   (f) $1 - \alpha = 0.99$

**Ans.** (a) 1.645   (b) 1.7511   (c) 1.8814
(d) 2.054   (e) 2.326   (f) 2.575

**Q.27** Determine the critical value of Z in each of the following circumstances:

**Ans.** (a) 1.16   (b) 1.24   (c) 1.2817

**Q.28** Determine the critical value of 't' in each of the following circumstances:

**Ans.** (a) 2.201   (b) 2.528   (c) 1.753   (d) 3.169

**Q.29** Write all the confidence intervals for population mean with small and large samples, population standard deviation being known and unknown.

**Q.30** State the formula which is used to calculate a 95 % confidence interval for the population mean $\mu$, when the population standard deviation $\sigma$ is known.

**Ans.** $\bar{X} - 1.96 \frac{\sigma}{\sqrt{n}} < \mu < \bar{X} + 1.96 \frac{\sigma}{\sqrt{n}}$

**Q.31** If $\bar{X} = 100$, $\sigma = 8$ and $n = 64$, set up a 95 % confidence interval estimate of the population mean $\mu$.

**Ans.** $98.04 < \mu < 101.96$

**Q.32** Given $n = 25$, $\bar{X} = 60$, $\sigma = 10$ and $1 - \alpha = 0.94$. Compute the 94% confidence interval for $\mu$.

**Ans.** $56.2372 < \mu < 63.7628$

**Q.33** Given $n = 16$, $\bar{X} = 52.5$, $\sigma = 10$ and $1 - \alpha = 0.90$. Compute the 90% confidence interval for $\mu$.

**Ans.** $48.3875 < \mu < 56.6125$

**Q.34** Given $N = 400$, $n = 64$, $\bar{X} = 50$, $\sigma = 10$ and $Z_{\alpha/2} = 2.575$. Find the confidence interval for $\mu$.

**Ans.** $47.05 < \mu < 52.95$

**Q.35** Given $N = 500$, $n = 100$, $\bar{X} = 60$, $\sigma = 5$ and $Z_{0.025} = 1.96$. Find the 95% confidence interval for $\mu$.

**Ans.** $59.12 < \mu < 60.88$

**Q.36** State the formula which is used to calculate a 92 % confidence interval for the population mean $\mu$, when the population standard deviation $\sigma$ is unknown and $n = 49$.

**Ans.** $\bar{X} - 1.7511 \frac{S}{7} < \mu < \bar{X} + 1.7511 \frac{S}{7}$

**Q.37** Given $n = 144$, $\bar{X} = 750$, $S = 6$ and $Z_{0.01} = 2.326$. Compute the 98% confidence interval for $\mu$.

**Ans.** $748.837 < \mu < 751.163$
