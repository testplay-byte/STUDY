# Page 31 — Statistical Inference Estimation (Chapter 14)

> 📄 Original scan: [0031.jpg](../../../Raw/Statistics/Chapter-14-Statistical-Inference-Estimation/0031.jpg) · printed page 233

**Q.38** State the formula which is used to calculate a 90 % confidence interval for the population mean $\mu$, when the population standard deviation $\sigma$ is unknown and $n = 10$.

**Ans.** $\bar{X} - 1.833 \frac{s}{\sqrt{10}} < \mu < \bar{X} + 1.833 \frac{s}{\sqrt{10}}$

**Q.39** Given $n = 16, \bar{X} = 80, s = 3$ and $t_{0.01(15)} = 2.602$. Construct the 98% confidence interval for population mean $\mu$.

**Ans.** $78.0485 < \mu < 81.9515$

**Q.40** If $n = 16, \sum(X - \bar{X})^2 = 135$ and $\bar{X} = 41.5$. Find 95% confidence interval for $\mu$.

**Ans.** $39.9 < \mu < 43.1$

**Q.41** State the formula which is used to calculate a 98 % confidence interval for the difference between two population means $\mu_1 - \mu_2$, when population variances are known with any sample size.

**Ans.** $(\bar{X}_1 - \bar{X}_2) - 2.326 \sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}} < \mu_1 - \mu_2 <$

$(\bar{X}_1 - \bar{X}_2) + 2.326 \sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}$

**Q.42** State the formula which is used to calculate a 98 % confidence interval for the difference between two population means , $\mu_1 - \mu_2$, when $\sigma_1 = \sigma_2$ and $n_1 = n_2$

**Ans.** $(\bar{X}_1 - \bar{X}_2) - 2.326 \sigma \sqrt{\frac{2}{n}} < \mu_1 - \mu_2 <$

$(\bar{X}_1 - \bar{X}_2) + 2.326 \sigma \sqrt{\frac{2}{n}}$

**Q.43** Given $n_1 = 32, n_2 = 50, \bar{X}_1 = 125, \bar{X}_2 = 100, \sigma_1^2 = 16, \sigma_2^2 = 25$ and $Z_{0.005} = 2.575$. Find the 99% confidence interval for the difference between population means $\mu_1 - \mu_2$.

**Ans.** $22.425 < \mu_1 - \mu_2 < 27.575$

**Q.44** State the formula which is used to calculate a 90% confidence interval for the difference between two population means $\mu_1 - \mu_2$, when population variances are unknown and $n_1 = n_2 = 40$.

**Ans.** $(\bar{X}_1 - \bar{X}_2) - 1.645 \sqrt{\frac{S_1^2}{40} + \frac{S_2^2}{40}} < \mu_1 - \mu_2 <$

$(\bar{X}_1 - \bar{X}_2) + 1.645 \sqrt{\frac{S_1^2}{40} + \frac{S_2^2}{40}}$

**Q.45** Given $n_1 = 48, \bar{X}_1 = 90, S_1^2 = 12, n_2 = 72, \bar{X}_2 = 85, S_2^2 = 18$ and $Z_{0.025} = 1.96$. Find the 95% confidence interval for $\mu_1 - \mu_2$.

**Ans.** $3.61 < \mu_1 - \mu_2 < 6.39$

**Q.46** Given the following summary statistics for independent random samples from two populations: $n_1 = 16, \bar{X}_1 = 60, s_1^2 = 36, n_2 = 9, \bar{X}_2 = 50, s_2^2 = 25, s_p = 5.67$ and $t_{0.05(23)} = 1.714$. Find the 90% confidence interval for $\mu_1 - \mu_2$.

**Ans.** $5.95 < \mu_1 - \mu_2 < 14.05$

**Q.47** State the formula which is used to calculate a 95 % confidence interval for the mean of a population of paired differences for $n = 9$.

**Ans.** $\bar{d} - 2.306 \frac{s_d}{3} < \mu_d < \bar{d} + 2.306 \frac{s_d}{3}$

**Q.48** Given $\bar{d} = 3, n = 9, s_d = 3$ and $t_{0.025(8)} = 2.306$. Find the 95% confidence interval for $\mu_d = \mu_1 - \mu_2$.

**Ans.** $0.694 < \mu_d < 5.306$

**Q.49** Write down any three confidence intervals of the t-distribution.

**Q.50** State the formula which is used to calculate a 92 % confidence interval for the population proportion p, when $n > 30$.

**Ans.** $\hat{p} - 1.7511 \sqrt{\frac{\hat{p}\hat{q}}{n}} < p < \hat{p} + 1.7511 \sqrt{\frac{\hat{p}\hat{q}}{n}}$

**Q.51** If X = 6 and n = 50. Find sample proportion $\hat{p}$.

**Ans.** 0.12.

**Q.52** Given $n = 500, \hat{p} = 0.30$ and $Z_{0.03} = 1.88$. Find the 94% confidence interval for the population proportion p.

**Ans.** $0.26 < p < 0.34$

**Q.53** Given $n_1 = 400, \hat{p}_1 = 0.8, n_2 = 300, \hat{p}_2 = 0.6$ and $Z_{0.04} = 1.75$. Find the 92% confidence interval for the difference between population proportions.

**Ans.** $0.14 < p_1 - p_2 < 0.26$

**Q.54** Given $n_1 = 600, \hat{p}_1 = 0.50, n_2 = 400, \hat{p}_2 = 0.25$ and $Z_{0.01} = 2.326$. Find the 98% confidence interval for the difference between population proportions.

**Ans.** $0.18 < p_1 - p_2 < 0\cdot 32$
