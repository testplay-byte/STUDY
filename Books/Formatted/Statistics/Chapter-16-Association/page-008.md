# Page 8 — Association (Chapter 16)

> 📄 Original scan: [0008.jpg](../../../Raw/Statistics/Chapter-16-Association/0008.jpg) · printed page 292

Consider the following sample data on the liking of males and females for fish.

| | Gender | | |
| :--- | :--- | :--- | :--- |
| | **Males (A)** | **Females ($\alpha$)** | **Total** |
| **Like Fish (B)** | $(AB) = 80$ | $(\alpha B) = 80$ | $(B) = 160$ |
| **Do Not Like Fish ($\beta$)** | $(A\beta) = 20$ | $(\alpha \beta) = 20$ | $(\beta) = 40$ |
| **Total** | $(A) = 100$ | $(\alpha) = 100$ | $n = 200$ |

Here, $(AB) = 80$ and $\frac{(A)(B)}{n} = \frac{(100)(160)}{200} = 80$. Therefore $(AB) = \frac{(A)(B)}{n} = 80$.

**Hence $A$ and $B$ are independent.**

It also implies independence between $A$ and $\beta$, $\alpha$ and $B$, $\alpha$ and $\beta$. Let us check another pairs.

$(A\beta) = 20$ and $\frac{(A)(\beta)}{n} = \frac{100(40)}{200} = 20$. Therefore $(A\beta) = \frac{(A)(\beta)}{n} = 20$

**Hence $A$ and $\beta$ are independent**

$(\alpha B) = 80$ and $\frac{(\alpha)(B)}{n} = \frac{(100)(160.)}{200} = 80$. Therefore $(\alpha B) = \frac{(\alpha)(B)}{n} = 80$.

**Hence $\alpha$ and $B$ are independent**

$(\alpha \beta) = 20$ and $\frac{(\alpha)(\beta)}{n} = \frac{(100)(40)}{200} = 20$. Therefore $(\alpha \beta) = \frac{(\alpha)(\beta)}{n} = 20$.

**Hence $\alpha$ and $\beta$ are independent.**

**Example 16.7.**

Whether attributes $A$ and $B$ are independent, positively associated or negatively associated?

(i) $(A) = 119, (AB) = 99, (\alpha\beta) = 5, (\alpha B) = 36, (A\beta) = 20$ and $n = 160$.

(ii) $(\alpha\beta) = 500, (\beta) = 700, (\alpha) = 800$ and $(A) = 600$.

(iii) $(A\beta) = 20, (\alpha) = 100, (\alpha B) = 40, (B) = 120$ and $n = 200$.

(iv) $(AB) = 20, (A) = 50, (\alpha\beta) = 29$ and $(\alpha) = 60$.

(v) $(A\beta) = 40, (\alpha\beta) = 40, (\alpha B) = 160$ and $n = 400$.

**Solution:** The necessary calculations are given below:

(i) 2 × 2 Contingency Table

| | A | $\alpha$ | Total |
| :--- | :--- | :--- | :--- |
| B | $(AB) = 99$ | $(\alpha B) = 36$ | $(B) = 135$ |
| $\beta$ | $(A\beta) = 20$ | $(\alpha \beta) = 5$ | $(\beta) = 25$ |
| Total | $(A) = 119$ | $(\alpha) = 41$ | $n = 160$ |

Here, $(AB) = 99$ and $\frac{(A)(B)}{n} = \frac{(119)(135)}{160} = 100.41$. Therefore

$(AB) < \frac{(A)(B)}{n}$ that is $99 < 100.41$. Hence A and B are negatively associated.

(ii) 2 × 2 Contingency Table

| | A | $\alpha$ | Total |
| :--- | :--- | :--- | :--- |
| B | $(AB) = 400$ | $(\alpha B) = 300$ | $(B) = 700$ |
| $\beta$ | $(A\beta) = 200$ | $(\alpha \beta) = 500$ | $(\beta) = 700$ |
| Total | $(A) = 600$ | $(\alpha) = 800$ | $n = 1400$ |

Here, $(AB) = 400$ and $\frac{(A)(B)}{n} = \frac{(600)(700)}{1400} = 300$. Therefore

$(AB) > \frac{(A)(B)}{n}$ that is $400 > 300$. Hence A and B are positively associated.
