(iii) 2 × 2 Contingency Table

| | A | $\alpha$ | Total |
| :--- | :--- | :--- | :--- |
| B | $(AB) = 80$ | $(\alpha B) = 40$ | $(B) = 120$ |
| $\beta$ | $(A\beta) = 20$ | $(\alpha \beta) = 60$ | $(\beta) = 80$ |
| Total | $(A) = 100$ | $(\alpha) = 100$ | $n = 200$ |

Here, $(AB) = 80$ and $\frac{(A)(B)}{n} = \frac{(100)(120)}{200} = 60$. Therefore

$(AB) > \frac{(A)(B)}{n}$ that is $80 > 60$. Hence A and B are positively associated.

(v) 2 × 2 Contingency Table

| | A | $\alpha$ | Total |
| :--- | :--- | :--- | :--- |
| B | $(AB) = 160$ | $(\alpha B) = 160$ | $(B) = 320$ |
| $\beta$ | $(A\beta) = 40$ | $(\alpha \beta) = 40$ | $(\beta) = 80$ |
| Total | $(A) = 200$ | $(\alpha) = 200$ | $n = 400$ |

Here, $(AB) = 160$ and $\frac{(A)(B)}{n} = \frac{(200)(320)}{400} = 160$. Therefore $(AB) = \frac{(A)(B)}{n} = 160$.

Hence attributes A and B are independent.

**Example 16.8.**

Men and women go to a certain store for buying the articles. They make the payment in cash or purchase on credit (loan). Investigate if there is any relation between mode of payment and the sex of the customer. Given the data below:

| | **Payment** | |
| :--- | :--- | :--- |
| **Sex** | **Cash** | **Credit** |
| Males | 80 | 40 |
| Females | 20 | 60 |

**Solution:** Let $A$ = Purchase on cash payment, $\alpha$ = Purchase on credit, $B$ = Males and $\beta$ = Females.

Let us write the table along with the symbols

| **Attributes** | **A** | **$\alpha$** | **Total** |
| :--- | :--- | :--- | :--- |
| B | $(AB) = 80$ | $(\alpha B) = 40$ | $(B) = 120$ |
| $\beta$ | $(A\beta) = 20$ | $(\alpha \beta) = 60$ | $(\beta) = 80$ |
| Total | $(A) = 100$ | $(\alpha) = 100$ | $n = 200$ |

$(AB) = 80$ and $\frac{(A)(B)}{n} = \frac{(100)(120)}{200} = 60$. Therefore $(AB) > \frac{(A)(B)}{n}$
