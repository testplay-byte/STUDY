## SHORT DEFINITIONS

**1. Attribute**

If a characteristic which is being measured is of qualitative nature, is called an attribute. Attributes are denoted by A, B, C, $\alpha$, $\beta$, $\gamma$, etc. The attributes A, B, C are the positive attributes and $\alpha$, $\beta$, $\gamma$ are negative attributes.

*or*

The characteristic being studied is nonnumeric, is known as an attribute.

**2. Examples of Attribute**

(i) Level of education.
(ii) Level of smoking.
(iii) Level of social work.
(iv) Religion and colour.
(v) Skilled workers.

**3. Variable**

A variable is a phenomenon that may vary from one individual or object to another.

*or*

A characteristic that can have different values is called a variable.

**4. Independence**

Two attributes A and B are said to be independent if $(AB) = \frac{(A)(B)}{N}$.

**5. Association**

If two attributes are not independent, they are said to be associated.

**6. Positive Association**

Two attributes A and B are said to be positively associated if $(AB) > \frac{(A)(B)}{N}$.

**7. Negative Association**

Two attributes A and B are said to be negatively associated if $(AB) < \frac{(A)(B)}{N}$.

**8. Cell Frequency**

The number of values or observations falling in a particular cell is called cell frequency.

**9. Class**

A class is a set of the observations which are sharing a given characteristic.

**10. Class Frequency**

A class frequency is the number of observations which are distributed in a class.

**11. Ultimate Class Frequency**

In a certain given situation, the ultimate class frequency is the frequency with the highest order. The number of ultimate class frequencies for k attributes is given by $2^k$. For two attributes, the number of ultimate class frequencies are $2^2 = 4$. That is $(AB)$, $(A\beta)$, $(\alpha B)$ and $(\alpha\beta)$. For three attributes it is $2^3 = 8$ and so on.

**12. Order of Class**

The order of the class depends upon the number of attributes going into that class. If a certain class can give us information about only one attribute, it is called class of order one. The classes A, $\alpha$, B are $\beta$ are classes of the order one. The classes AB, A$\beta$, $\alpha$B and $\alpha\beta$ are the classes of order two, etc.

**13. Consistent and Inconsistent Data**

If the class frequencies are observed in a certain sample data and all class frequencies are recorded correctly, then there will be no error in them and they will be called consistent. A simple test of consistency is that all frequencies should be positive, otherwise there will be inconsistency in the sample data.

**14. Contrary Classes**

The mixed classes of both positive and negative attributes, they are called contrary classes. For example $(A\beta)$, $(\alpha B)$, $(AB\gamma)$, $(A\beta C)$, $(\alpha\beta C)$, etc.

**15. Dichotomy**

The objects or individuals can be divided into two distinct and mutually exclusive classes according to whether the objects do or do not possess a particular attribute. This process of dividing the objects into two mutually exclusive classes is called dichotomy.

**16. Multinomial Population**

If each observation of a population is assigned to one and only one of more than two attribute categories, the population is called a multinomial population.

**17. Contingency Table**

A table showing the cross-tabulation or joint distribution of two variables is known as contingency table.

*or*

A table used to classify sample observations according to two or more identifiable characteristics is called contingency table.
