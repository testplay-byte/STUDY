# Page 31 — Association (Chapter 16)

> 📄 Original scan: [0031.jpg](../../../Raw/Statistics/Chapter-16-Association/0031.jpg) · printed page 315

**Q.9** Find coefficient of association from the following data:

|  | Height of fathers |  |
| :--- | :--- | :--- |
| **Height of sons** | **Tall** | **Short** |
| Tall | 500 | 100 |
| Short | 100 | 400 |

**Ans.** Q = 0.905, positive association between height of fathers and height of sons.

**Q.10** 1660 candidates appeared for an examination and 422 were successful. 256 had attended a coaching class and of these 150 came out successful. Find the coefficient of association between success and coaching a class.

**Ans.** 0.71.

**Q.11** Can vaccination be regarded as preventive measure for smallpox from the following data of 1482 persons in a locality exposed to smallpox, 368 in all were attacked of 1482 persons, 343 persons had been vaccinated and of these 35 were attacked.

**Ans.** 0.57

**Q.12** Discuss association between two attributes using 5% level of significance.

| Attributes | $B_1$ | $B_2$ |
| :--- | :--- | :--- |
| $A_1$ | 46 | 80 |
| $A_2$ | 54 | 120 |

**Ans.** $\chi^2 = 0.9853$, Accept $H_o$.

**Q.13** Test the association between two attributes A and B from the following data. Let α = 0.05.

| Attributes | $A_1$ | $A_2$ |
| :--- | :--- | :--- |
| $B_1$ | 20 | 30 |
| $B_2$ | 15 | 35 |

**Ans.** $\chi^2 = 1.1$, Accept $H_o$.

**Q.14** From the following table, test the hypothesis that the flower colour is independent of flatness of leaf. Use α = 0.05

|  | Flat leaves | Lean leaves | Total |
| :--- | :--- | :--- | :--- |
| **White flowers** | 99 | 36 | 135 |
| **Red flowers** | 20 | 5 | 25 |
| **Total** | 119 | 41 | 160 |

**Ans.** $\chi^2 = 0.494$, Accept $H_o$.

**Q.15** In a locality, 300 persons were randomly selected and asked about their educational attainment. The results are given as follows:

|  | Education |  |  |
| :--- | :--- | :--- | :--- |
| **Sex** | **Middle** | **Secondary school** | **College** |
| Male | 30 | 45 | 75 |
| Female | 75 | 30 | 45 |

Can we say that education depends on sex? Use α = 0.05.

**Ans.** $\chi^2 = 29.786$, Reject $H_o$.
