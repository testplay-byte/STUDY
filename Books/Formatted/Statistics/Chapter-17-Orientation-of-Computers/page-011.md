## SHORT DEFINITIONS

**1. Computer**

A computer is an electronic machine that accepts information, stores it until the information is needed, processes the information according to the instructions provided by the user and finally returns the results to the user. The computer consists of hardware and software. The machine is called hardware and program is called software. There are four elements of computer:
(i) Input devices (ii) Processing devices
(iii) Output devices and (iv) Storage devices.

**2. Types of Computer**
(i) Analog Computers (ii) Digital Computers
(iii) Hybrid Computers

**3. Analog Computer**

An analog computer represents data as physical quantities and operates on the data by manipulating the quantities.

**4. Digital Computers**

A digital computer is designed to process data in numerical form. Its circuits perform directly the mathematical operations of addition, subtraction, multiplication and division.

**5. Hybrid Computer**

A Hybrid Computer is the combination of the best features of Analog and Digital Computer, e.g. it possesses the faster speed like Analog Computer and accuracy like Digital Computer. It can measure both in terms of physical as well as digital quantities.

**6. Main Categories of Computer**
(i) Mainframe computers (ii) Minicomputers
(iii) Microcomputers (iv) Super computers

**7. Super Computer**

Super computer is the most expensive computer. Most people do not have a direct need for the speed and power of a super computer. Super computer process billions of instructions per second. The super computer is mainly used for tasks such as worldwide weather forecasting and weapons research. But now super computer is also moving toward the mainstream, for activities as varied as stock analysis, automobile design, special effects for movies and even sophisticated artworks.

**8. Computer Components**
(i) Compute hardware (ii) Computer software

**9. Hardware**

The electronic and mechanical components of a computer are known as computer hardware. These components can be physically handled. The function of these components is typically divided into three main categories:
(i) Input (ii) Output (iii) Storage
Keyboard, mouse, monitor, system unit are some of the common examples of computer hardware.

**10. Software**

A set of instructions given to the computer to perform a specific task, is called software. Software is also called computer program.

**11. Functions of a System Software**

System software are the programs' that manage computer resources at a low level. System software are categorized into the following two types:
(i) Operating system (ii) Language processor
Operating system perform basic tasks, such as recognizing input from the keyboard, sending output to the display screen, keeping track of files and directories on the disk.
Language processor also known as translator is a software that performs language translation.

**12. Input Devices**

Input devices provides communication between the user and the computer. Examples of input devices are:
(i) Mouse (ii) Keyboard
(iii) Light pen (iv) Joystick.

**13. Output Devices**

The devices which are used to get information or result from computer are called output devices. These are a communication link between a computer and user. The output devices can be of two types:
(i) Soft copy (ii) Hard copy

**14. Central Processing Unit ( CPU )**

Central processing unit is the electronic brain of the computer. In addition to processing data, it controls the functions of all the other components. It consists of three components that is control unit, arithmetic logic unit and main memory.
