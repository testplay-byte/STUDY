## SHORT DEFINITIONS

**37. Data Processing**

The process of converting data into information is called data processing. Data processing is also known as computing. In data processing, data is used as input and information is the output.

**38. Pointing Device**

The device that is used to control the position of pointer on the computer screen is called pointing device.

**39. Types of Printers**
(i) Dot Matrices (ii) Laser Printers
(iii) Laser Jet (iv) Ink Jet Printer

**40. Byte**

In most computer system, a byte consists of eight bits. One character takes one byte of memory. The storage capacity of the memory is expressed in terms of number of bytes. The data and program size are also measured in bytes.

**41. Decimal Number System**

Decimal number system is most widely used number system of the world ranging from 0 – 9. The base of decimal system is considered to be 10.

**42. Binary Number System**

The binary system is consist of two digits 0 and 1 and these two digits suits to the electronic machine.

**43. Octal Number System**

The octal number system is composed of eight digits, ranging from 0 to 7. The base of this system is eight.

**44. Hexadecimal Number System**

The hexadecimal number system is composed of sixteen digits. The first 10 digits of this system are 0 to 9 and the remaining six digits are denoted by A, B, C, D, E, F representing the decimal values 10, 11, 12, 13, 14, 15 respectively.
