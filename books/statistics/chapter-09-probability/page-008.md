**Example 9.2.**

One day 20 files were presented to an income tax officer for disposal. Five files contained bogus entries. All the files were thoroughly mixed and there was no indication about bogus files. What is the probability that one file with bogus entries is selected?

**Solution:** Here all possible outcomes $= 20 = \text{n(S)}$

Let A be the event that the file has bogus entries. Thus, number of favourable outcomes $= 5 = \text{n(A)}$.

Here we shall apply the classical definition of probability. All the 20 files are assumed to be equally likely for the purpose of selecting a file. Probability of selecting a file with bogus entries is written as P(A)

$$\text{Thus, P(A)} = \frac{\text{Number of outcomes favourable to A}}{\text{Number of possible outcomes in S}} = \frac{\text{n(A)}}{\text{n(S)}} = \frac{5}{20} = \frac{1}{4}$$

**Example 9.3.**

A class of 60 students has 30 first divisioners, 20 second divisioners and 10 third divisioners. One student is selected at random. Find the probability that the selected student is (i) a first divisioner (ii) first or second divisioner (iii) second or third divisioner.

**Solution:** There are sixty students in all. Thus there are 60 possible outcomes in S which are assumed to be equally likely. We shall apply the classical definition of probability to find the required probabilities

(i) Let A be the event that the selected student is a first divisioner. There are 30 outcomes favourable to the event A. Thus the probability of the event A denoted by P(A) is

$$\text{P(A)} = \frac{\text{Number of outcomes favourable to A}}{\text{Number of possible outcomes in S}} = \frac{\text{n(A)}}{\text{n(S)}} = \frac{30}{60} = \frac{1}{2}$$

(ii) Let B be the event that the selected student is a first or second divisioner. Then the number of outcomes favourable to B is 50. Therefore

$$\text{P(B)} = \frac{\text{Number of outcomes favourable to B}}{\text{Number of possible outcomes in S}} = \frac{\text{n(B)}}{\text{n(S)}} = \frac{50}{60} = \frac{5}{6}$$

(iii) Let C be the event that the selected student is a second or third divisioner. Then the number of outcomes favourable to C is 30. Therefore

$$\text{P(C)} = \frac{\text{Number of outcomes favourable to C}}{\text{Number of possible outcomes in S}} = \frac{\text{n(C)}}{\text{n(S)}} = \frac{30}{60} = \frac{1}{2}$$

**Example 9.4.**

A fair die is rolled. Find the probabilities that the face on the die is
(i) maximum (ii) prime (iii) multiple of 3 (iv) multiple of 7.

**Solution:** There are 6 possible outcomes when a die is rolled. We assume that all the 6 faces are equally likely. The classical definition of probability is to be applied here. The sample space is

$$\text{S} = \{1, 2, 3, 4, 5, 6\}, \quad \text{n(S)} = 6$$

(i) Let A be the event that the face is maximum, then

$$\text{A} = \{6\}, \quad \text{n(A)} = 1, \quad \text{P(A)} = \frac{\text{n(A)}}{\text{n(S)}} = \frac{1}{6}$$

(ii) Let B be the event that the face is prime, then

$$\text{B} = \{2, 3, 5\}, \quad \text{n(B)} = 3, \quad \text{P(B)} = \frac{\text{n(B)}}{\text{n(S)}} = \frac{3}{6} = \frac{1}{2}$$

(iii) Let C be the event that the face is multiple of 3, then

$$\text{C} = \{3, 6\}, \quad \text{n(C)} = 2, \quad \text{P(C)} = \frac{\text{n(C)}}{\text{n(S)}} = \frac{2}{6} = \frac{1}{3}$$

(iv) Let D be the event that face is multiple of 7. There is no multiple of 7 in the sample space, then

$$\text{D} = \{\} = \phi, \quad \text{n(D)} = 0, \quad \text{P(D)} = \frac{\text{n(D)}}{\text{n(S)}} = 0$$
