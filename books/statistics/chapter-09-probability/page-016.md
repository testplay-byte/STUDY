# Page 16 — Probability (Chapter 9)

> 📄 Original scan: [0016.jpg](../raw/S-2/0016.jpg) · printed page 26

**Example 9.15.**

A coin is tossed 6 times. Find the probability that there is at least one head.

**Solution:** The sample space S has $2^6 = 64$ possible outcomes. There is only one outcome ( TTTTTT ) in S which does not have any head. All the other 63 outcomes have either one or more heads.

It is difficult to write all the 63 outcomes. Let A be the event "at least one head" and $\bar{A}$ be the event "no head".

A and $\bar{A}$ are mutually exclusive and exhaustive events, therefore

$$\text{A} \cup \bar{\text{A}} = \text{S} \quad \text{and} \quad \text{P(A} \cup \bar{\text{A}}) = \text{P(S)}$$

$$\text{P(A)} + \text{P(}\bar{\text{A}}) = 1 \quad \text{or} \quad \text{P(A)} = 1 - \text{P(}\bar{\text{A}}) = 1 - \frac{1}{64} = \frac{63}{64} = \text{P(at least one head)}$$

**Example 9.16.**

A card is selected at random from a deck of playing cards. Find the probability that the card is a king or a queen.

**Solution:** There are 52 possible outcomes which are equally likely. Each card has probability of 1/52.

Let A represent the event "card is a king" and B represent the event "card is a queen". There are 4 kings and 4 queens in a deck. The events A and B are mutually exclusive, therefore

$$\text{P(A} \cup \text{B)} = \text{P(A)} + \text{P(B)} = \frac{4}{52} + \frac{4}{52} = \frac{8}{52}$$

**Example 9.17.**

A die is rolled. Find the following probabilities.
(i) The face is multiple of 3 or multiple of 5.
(ii) The face is a complete square or it is the maximum face.

**Solution:** When a die is rolled, the sample space will be $\text{S} = \{ 1, 2, 3, 4, 5, 6 \}$, $\text{n(S)} = 6$

(i) $\text{A} = \text{face is multiple of } 3 = \{ 3, 6 \}, \text{n(A)} = 2, \text{P(A)} = \frac{\text{n(A)}}{\text{n(S)}} = \frac{2}{6}$

$\text{B} = \text{face is multiple of } 5 = \{ 5 \}, \text{n(B)} = 1, \text{P(B)} = \frac{\text{n(B)}}{\text{n(S)}} = \frac{1}{6}$

A and B are mutually exclusive events, therefore

$$\text{P(A} \cup \text{B)} = \text{P(A)} + \text{P(B)} = \frac{2}{6} + \frac{1}{6} = \frac{3}{6} = \frac{1}{2}$$

**Alternately Method:**

$\text{A} = \{ 3, 6 \}, \quad \text{B} = \{ 5 \} \quad \text{A} \cup \text{B} = \{ 3, 5, 6 \} \text{ and n(A} \cup \text{B)} = 3.$

From the classical definition of probability of an event, therefore

$$\text{P(A} \cup \text{B)} = \frac{\text{Number of outcomes in A} \cup \text{B}}{\text{Total number of possible outcomes}} = \frac{\text{n(A} \cup \text{B)}}{\text{n(S)}} = \frac{3}{6} = \frac{1}{2}$$

(ii) $\text{A} = \text{face is a complete square} = \{ 1, 4 \}, \text{n(A)} = 2, \text{P(A)} = \frac{\text{n(A)}}{\text{n(S)}} = \frac{2}{6}$

$\text{B} = \text{face is maximum} = \{ 6 \}, \text{n(B)} = 1, \text{P(B)} = \frac{\text{n(B)}}{\text{n(S)}} = \frac{1}{6}$

A and B are mutually exclusive events, therefore

$$\text{P(A} \cup \text{B)} = \text{P(A)} + \text{P(B)} = \frac{2}{6} + \frac{1}{6} = \frac{3}{6} = \frac{1}{2}$$

**Alternately Method:**

$\text{A} = \{ 1, 4 \} \quad \text{B} = \{ 6 \} \quad \text{A} \cup \text{B} = \{ 1, 4, 6 \} \text{ and n(A} \cup \text{B)} = 3$

$$\text{P(A} \cup \text{B)} = \frac{\text{Number of outcomes in A} \cup \text{B}}{\text{Total number of possible outcomes}} = \frac{\text{n(A} \cup \text{B)}}{\text{n(S)}} = \frac{3}{6} = \frac{1}{2}$$
