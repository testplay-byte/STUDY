**Example 9.45.**

A container has 3 good items and 2 defective items. Two items are selected with replacement. Find the following probabilities.

(i) both are good, (ii) one is good and one is defective (iii) both are defective

**Solution:**

| | Good items | Defective items | Total items |
| :--- | :--- | :--- | :--- |
| **Container:** | 3 | 2 | 5 |

(i) $\text{P( first is good )} = \text{P(A)} = \frac{3}{5}$ and $\text{P( second is good )} = \text{P(B)} = \frac{3}{5}$

Since A and B are independent events, therefore

$\text{P(both are good)} = (\text{P(A} \cap \text{B)}) = \text{P(A) P(B)} = \left(\frac{3}{5}\right)\left(\frac{3}{5}\right) = \frac{9}{25} = 0.36$

(ii) $\text{P( first is good )} = \text{P(G}_1\text{)} = \frac{3}{5}$ and $\text{P( second is defective )} = \text{P(D}_2\text{)} = \frac{2}{5}$

Since G$_1$ and D$_2$ are independent events, therefore

$\text{P(G}_1 \cap \text{D}_2\text{)} = \text{P(G}_1\text{) P(D}_2\text{)} = \left(\frac{3}{5}\right)\left(\frac{2}{5}\right) = \frac{6}{25}$

Similarly

$\text{P( first is defective )} = \text{P(D}_1\text{)} = \frac{2}{5}$ and $\text{P( second is good )} = \text{P(G}_2\text{)} = \frac{3}{5}$

Since D$_1$ and G$_2$ are independent events, therefore

$\text{P(D}_1 \cap \text{G}_2\text{)} = \text{P(D}_1\text{) P(G}_2\text{)} = \left(\frac{2}{5}\right)\left(\frac{3}{5}\right) = \frac{6}{25}$

$\text{P( one is good and one is defective )} = \text{P(G}_1 \cap \text{D}_2\text{)} + \text{P(D}_1 \cap \text{G}_2\text{)} = \frac{6}{25} + \frac{6}{25} = \frac{12}{25} = 0.48$

(iii) $\text{P( first is defective )} = \text{P(D}_1\text{)} = \frac{2}{5}$ and $\text{P( second is defective )} = \text{P(D}_2\text{)} = \frac{2}{5}$

Since D$_1$ and D$_2$ are independent events, therefore

$\text{P(D}_1 \cap \text{D}_2\text{)} = \text{P(D}_1\text{) P(D}_2\text{)} = \left(\frac{2}{5}\right)\left(\frac{2}{5}\right) = \frac{4}{25} = 0.16$
