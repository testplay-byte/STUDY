**(b) Square Root Function**

The function of the form $y = \sqrt{x}$, where $x \geq 0$ is called a **square root function**.

For example,

$f(x) = \sqrt{x + 2}$ and $g(x) = \sqrt{x^2 - 3}$

are square root functions.

The domain of square root function depends upon its formation.

[Figure F1]

## 1.5 Plotting Graph of Function of the Type $y = x^n$

### 1.5.1 Graph of the Function $y = x^n$; $n \in Z \wedge x \neq 0$

For plotting the graph of the function $y = x^n$; $n \in Z \wedge x \neq 0$, we take different integral values of $n$. For example, the table for the function $y = \pm x^3$ is:

| $x$ | 0 | 0.5 | 1 | 2 |
| :--- | :-: | :-: | :-: | :-: |
| $f(x) = x^3$ | 0 | 0.125 | 1 | 8 |
| $g(x) = -x^3$ | 0 | −0.125 | −1 | −8 |

[Figure F2]

We observe that graphs of $y = x^3$ and $y = -x^3$ have the same shape but opposite behavior.

The graph of $y = x^n$ for $n = -2, -1, 0, 1, 2$ is shown below.

[Figure F3]

From the above graphs, we observe that:

$\succ$ the graph of $y = x^0$ is a horizontal line passing through $y = 1$.

$\succ$ the graph of $y = x^1$ is a straight line bisecting first and third quadrant.

$\succ$ the graph of $y = x^{-1}$ is a hyperbola passing through first and third quadrant.
