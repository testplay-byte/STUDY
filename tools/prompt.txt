PART 2 — BODY STRUCTURE
============================================================
1. H1: `# Page <page_image> — <chapter/unit or book context>`
2. Then exactly one line: `> 📄 Original scan: [<image filename>](<source_image path>) · printed page <page_printed or 'n/a'>`
3. Then the complete transcription of the page in original reading order (top→bottom, left→right; if multi-column, finish column 1 then column 2).
4. If the page has any figures, end with `## Figures on this page` and one `### Figure F<k>` block per figure (k = 1,2,3…).

============================================================
PART 3 — TRANSCRIPTION RULES (all binding)
============================================================
R1. VERBATIM TEXT: transcribe every instructional word: headings, paragraphs, definitions, examples, solutions, remarks. Preserve wording, spelling and order. Keep paragraph breaks where the page has them.
R2. HEADING HIERARCHY: printed section headings (e.g. "1.11.2 Graph of y = tanθ and y = cotθ") become `##`/`###` Markdown headings keeping their printed numbers. Sub-headings one level deeper.
R3. MATHEMATICS = LATEX: every formula, expression, symbol sequence in LaTeX. Inline in $…$, display equations in $$…$$. Use proper commands: \theta \sin \cos \tan \sec \csc \cot \neq \in \notin \subseteq \subset \cup \cap \times \phi \emptyset \bar{A} \frac{a}{b} \binom{n}{r} ^{n}P_{r} \leq \geq \ldots \infty \forall \exists \Rightarrow \leftrightarrow \{ \}. Set-builder like {x / x ∈ A and x ∈ B} → $\{x / x \in A \text{ and } x \in B\}$. Prescribe (overlines) with \bar{}. Preserve equation labels like (1), (i), (viii).
R4. TABLES = GFM: every printed table becomes a GitHub-Flavored Markdown table with exact row/column values; put its caption/number as bold text line above, e.g. **Table — Function/Domain/Range**. Never drop columns/rows; long tables keep all columns.
R5. FIGURES ARE SACRED — NEVER SKIP ANY. For every graph, diagram, illustration, photograph, tree diagram, map, icon set: (a) at its position in the reading flow insert `[Figure F1]` reference marker; (b) produce a block in the Figures section:
   ### Figure F1 — <short name + page position, e.g. "graphs of y = tanθ (top right)">
   - **Type:** line-graph | curve-plot | venn-diagram | tree-diagram | geometric-diagram | illustration | photo | scatter | histogram | other
   - **Caption/Number:** <printed caption e.g. "Figure-8", else "(none printed)">
   - **Description:** exhaustive visual description — axes & labels, scale/ticks, all curves/lines and their shapes/directions, asymptotes, marked/labeled points, intercepts, shaded regions (what exactly is shaded), legend, colors, annotations, sub-panels.
   - **Mathematical meaning:** one line on what it demonstrates (e.g. "y = tanθ has vertical asymptotes at θ = (2n+1)π/2 with period π; range is all reals").
R6. EXERCISE NUMBERING EXACT: question labels (Q.1, Q.10), sub-parts ((i)…(viii)), MCQ options, marks in brackets — all exactly as printed, never renumbered. Options as a list; sub-parts indented. If an answer line ("Ans.") is printed, transcribe it too.
R7. PAGE FURNITURE: running headers ("UNIT-01: FUNCTIONS AND GRAPHS", "[Chapter 8] Set Theory"), footers ("GRADE 12", publisher name, printed page number, navigation chips like "← 08 →") do NOT go into the body. They are captured in frontmatter/H1/scan-line only. For page_printed: transcribe the exact printed digits; never invent them.
R8. VISUAL EMPHASIS: keep bold as **bold**, colored/display boxes as blockquotes, so emphasis survives.
R9. ILLEGIBLE: give best guess + `[illegible]` marker, and list it in notes.
R10. SCAN ARTIFACTS: speckles, stains, skew, page-edge shadows are NOT content — never transcribe them.
R11. NO OMISSIONS, NO TRUNCATION: transcribe the entire page; if long, keep going to the very end.
